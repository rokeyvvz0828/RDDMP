# 11: CLB、DNS 与证书工单

Source: ../../spec.md
Spec coverage: User Stories 110-112
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 复用平台工作流提供 CLB 开通与调整、DNS 新增变更注销、证书申请续期吊销三类工单，登记业务申请和外部办理结果而不建设外部资源管理平台。

**Blocked by:** Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 用户能够按权限创建、保存、提交、查询和跟踪三类工单，并查看办理意见、结果和操作历史。
- [ ] CLB 工单只覆盖开通和调整，不维护 CLB 实例、监听器、后端池或健康检查生命周期。
- [ ] DNS 工单覆盖新增、变更和注销，实际 DNS 操作在线下或外部系统完成并由办理人登记结果。
- [ ] 证书工单覆盖申请、续期和吊销；平台不生成证书、不保存私钥、不自动部署。
- [ ] 附件只承载申请材料或公开证书，并继承工单实体授权和审计规则。
- [ ] 三类业务复用平台流程、通知和办理能力，但保持各自独立字段契约与校验。
- [ ] 真实 HTTP、MySQL/Flyway、工作流、越权和敏感数据测试，以及桌面端和移动端旅程通过验收。
