# 03: 具体环境与资源申请

Source: ../../spec.md
Spec coverage: User Stories 24-32
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 提供环境类型、具体环境及资源申请的完整入口，使申请人能够在一个物理子系统和一个具体环境下连续填写多个部署单元的资源需求，并通过平台工作流办理。

**Blocked by:** 02“部署单元版本与初始化导入”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 管理人员能够维护环境类型和具体环境；有业务引用的环境不能删除，停用只限制新业务。
- [ ] 用户能够查看具体环境基础信息以及申请态和实际态资源的明确分区，不能维护重复资源台账。
- [ ] 资源申请固定一个物理子系统和具体环境，并级联选择其下多个部署单元。
- [ ] 每条需求规格支持 CPU、内存、存储、计划节点数等已批准字段，同一部署单元的不同规格可直接复制明细。
- [ ] 申请可从搭建任务发起或独立创建，并复用平台工作流完成草稿、提交、办理和结果追踪。
- [ ] 失效物理子系统、停用部署单元或停用环境不能用于新申请，服务端必须执行相同校验。
- [ ] 真实 HTTP、MySQL/Flyway、工作流、权限审计和桌面端及移动端表单旅程通过验收。
