# 05: 搭建模板与计划生成

Source: ../../spec.md
Spec coverage: User Stories 50-65
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 建立“计划模板和任务模板 → 搭建计划 → 环节 → 任务 → 检查项”的生成链路，使计划责任人按目标范围批量生成可独立执行且不受后续模板变化影响的计划快照。

**Blocked by:** 02“部署单元版本与初始化导入”；03“具体环境与资源申请”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 模板管理员能够发布版本化计划模板和任务模板，已发布版本不可原地改写。
- [ ] 任务模板包含标准检查项，并支持“不展开”“按物理子系统”“按部署单元”三种生成维度。
- [ ] 计划只能从已发布模板创建，一个具体环境可以拥有多个相互独立且目标重叠的计划。
- [ ] 计划责任人选择目标后，系统按模板分别生成对应任务和独立检查项，未选择目标不进入计划。
- [ ] 计划保存模板版本、目标和关联信息快照，后续模板或架构资产变化只产生差异提示。
- [ ] 计划、环节、任务责任人和参与人可继承默认值并在生成后按权限调整，所有变化留痕。
- [ ] 真实 HTTP、MySQL/Flyway、版本并发、权限审计和桌面端及移动端计划创建旅程通过验收。
