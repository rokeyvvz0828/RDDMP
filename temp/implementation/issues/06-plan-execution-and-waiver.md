# 06: 搭建任务执行与豁免

Source: ../../spec.md
Spec coverage: User Stories 66-68, 75-86
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 让任务责任人和参与人执行任务及检查项，并由系统计算任务、环节和计划的完成状态与进度，同时提供可审计的取消豁免、恢复和重新打开机制。

**Blocked by:** 05“搭建模板与计划生成”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 满足准入条件的任务能够开始，检查项支持完成、重新打开、备注和可选附件并保留事件历史。
- [ ] 任务、环节和计划按当前有效检查项自下而上计算状态和进度，不提供通用状态或人工进度覆盖入口。
- [ ] 计划责任人可附原因取消未完成检查项、任务、环节或计划；其他执行人员只能提出检查项取消建议。
- [ ] 取消内容不物理删除且退出当前完成条件和进度，恢复后重新纳入并触发完整重算。
- [ ] 全部检查项或任务被取消时显示明确的“全部豁免”，全部环节取消时计划不得自动完成。
- [ ] 当前有效检查项重新打开后，已经完成的上级对象立即退出完成状态，并保留历次完成历史。
- [ ] 确定性规则单元测试、公开 API 场景、真实 MySQL、权限审计和桌面端及移动端执行旅程通过验收。
