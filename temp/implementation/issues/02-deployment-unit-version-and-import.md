# 02: 部署单元版本与初始化导入

Source: ../../spec.md
Spec coverage: User Stories 15-23
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 为技术架构师提供部署单元的稳定身份、版本发布、停用、作废和受控初始化导入，使部署单元成为可跨环境复用且历史可追溯的架构定义。

**Blocked by:** 01“架构子系统全生命周期”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 技术架构师能够在已发布物理子系统下维护具有独立生命周期的部署单元，并支持数据库、MQ 等符合边界的部署对象。
- [ ] 部署单元编号发布后不可修改或复用，显示名称和版本变化不改变稳定身份。
- [ ] 已发布部署单元不能直接改挂物理子系统；停用和作废遵守引用约束并保留历史。
- [ ] 已发布版本不可原地改写，新版本不会自动修改既有计划快照或环境部署实例。
- [ ] 初始化导入具备文件预览、关系校验、确认写入、批次记录、成功失败明细和错误报告。
- [ ] 只有技术架构师可执行导入和维护写操作，查询、导出和附件访问遵守服务端授权和审计要求。
- [ ] 公开 API、真实 MySQL/Flyway、导入失败回滚及桌面端和移动端主要旅程均通过验收。
