# 04: 资源下发与环境部署实例

Source: ../../spec.md
Spec coverage: User Stories 33-49
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 将资源工单的实际办理结果逐台落成环境部署实例和实际资源分配，并支持后续扩缩容、规格调整、资源汇总、实例下线、设计版本差异和灾备关系。

**Blocked by:** 03“具体环境与资源申请”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 办理人员按实际机器和 IP 逐台登记资源，成功结果形成唯一归属的环境部署实例和实际资源分配。
- [ ] 系统展示申请值与实际值差异并记录原因，实例和资源事实能够追溯来源工单及变更前后值。
- [ ] 扩容、缩容以及 CPU、内存、存储调整只能通过资源工单办理，不能直接覆盖实际资源事实。
- [ ] 申请态资源总量与实际态资源总量按规格、节点和未下线实例分别计算，实际节点数不允许人工维护。
- [ ] 普通用户不能手工创建或改挂实例；机器用途或 IP 变化通过下线旧实例、创建新实例保留两段历史。
- [ ] 实例支持在用和已下线状态、采用的部署单元版本差异、同部署单元实例间灾备关系以及下线关联风险。
- [ ] 唯一性、并发、历史保留、真实 MySQL/Flyway、公开 API、权限审计和桌面端及移动端旅程通过验收。
