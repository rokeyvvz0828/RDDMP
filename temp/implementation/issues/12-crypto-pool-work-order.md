# 12: 加密机入池工单

Source: ../../spec.md
Spec coverage: User Stories 113-119
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 为一个物理子系统下的一个部署单元提供加密机入池申请和办理台账，记录安全节点快照、多条接口、峰值交易量、权威目录引用、临时接口和外部办理结果。

**Blocked by:** 02“部署单元版本与初始化导入”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 申请人能够级联选择一个物理子系统和一个部署单元创建、保存和提交入池工单。
- [ ] 安全节点号从物理子系统主记录带出并保存提交快照，工单中不能另行改写。
- [ ] 一张工单支持多条接口项，每项包含预计峰值交易量和计量单位，工单总量由明细计算。
- [ ] 接口优先引用权威目录并保留快照，目录外接口必须明确标记为临时接口。
- [ ] 办理人通过平台工作流核验、补充、退回、受理并登记结果和凭证，完成表示外部配置已经办理。
- [ ] 平台不得自动分配加密机资源、创建外部协同任务或执行配置。
- [ ] 真实 HTTP、MySQL/Flyway、工作流、权限审计、汇总规则和桌面端及移动端旅程通过验收。
