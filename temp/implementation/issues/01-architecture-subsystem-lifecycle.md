# 01: 架构子系统全生命周期

Source: ../../spec.md
Spec coverage: User Stories 1-14
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 为应用架构师、申请人和技术人员提供逻辑子系统与物理子系统的完整纵向能力，包括查询维护、物理子系统变更申请、确定性编号、智能补全、审批发布、归属调整、作废和下线，并保证建议、申请与已发布主记录相互分离。

**Blocked by:** Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 应用架构师能够维护逻辑子系统，已认证用户能够按授权范围查询逻辑与物理子系统。
- [ ] 申请人能够保存和提交物理子系统新增、修改、作废或下线申请，同一物理子系统不能同时存在多张未结束申请。
- [ ] 编号由确定性规则生成并执行唯一性校验；智能补全只提供可主动采用的建议，不覆盖人工值或直接修改主记录。
- [ ] 应用架构师能够调整最终发布值并查看提交值与发布值差异，只有批准后才更新物理子系统主记录。
- [ ] 作废、下线和逻辑子系统归属调整遵守引用约束并保留不可删除、不可复用的完整历史。
- [ ] 服务端认证、角色权限、数据范围、实体授权和关键写操作审计均有公开 API 场景覆盖。
- [ ] 使用真实 MySQL/Flyway 和真实工作流完成自动化验收，并在桌面端、移动端验证核心申请与审批旅程。
