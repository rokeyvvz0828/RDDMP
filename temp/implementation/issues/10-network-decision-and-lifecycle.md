# 10: 网络访问判定与关系生命周期

Source: ../../spec.md
Spec coverage: User Stories 98-99, 106, 108-109
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 根据网络隔离规则与现有有效访问关系进行严格的申请判定，并通过修改、续期和关闭申请维护关系生命周期及下线实例风险。

**Blocked by:** 09“网络分区与访问关系”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 用户输入源、目标、端口、协议和时间范围后只能得到“需要申请”或“不需要申请”的明确结论。
- [ ] 只有所有适用规则明确无需申请，或已有有效关系完整覆盖地址、端口、协议和时间范围时返回“不需要申请”。
- [ ] 未知规则、缺失输入、范围覆盖不全或判定异常均严格返回“需要申请”，不能默认放行。
- [ ] 限时关系使用明确开始和结束时间，长期关系不使用遥远日期占位。
- [ ] 修改、续期和关闭只能通过新申请办理，既有已开通关系不得直接编辑或删除。
- [ ] 实例下线不自动关闭历史关系，但显示风险且禁止下线实例用于新申请。
- [ ] 判定规则单元测试、时间边界、公开 API、真实 MySQL、工作流、权限审计和浏览器旅程通过验收。
