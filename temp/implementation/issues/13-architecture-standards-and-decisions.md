# 13: 架构规范与架构决策

Source: ../../spec.md
Spec coverage: User Stories 120-131
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 提供统一的架构规范分类发布与查阅能力，并把一事一议的架构决策从事项提交、首次处理、补充、异步或会议评审推进到正式结论发布和替代链追溯。

**Blocked by:** Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 维护人员能够按平台字典分类发布和维护架构规范，技术人员能够按权限在线查阅及预览附件。
- [ ] PDF 只作为附件格式，部署公告和网络规划文档不形成独立模块，结构化网络数据不被文档替代。
- [ ] 提出人能够围绕一个问题提交决策事项，首次提交允许材料不完整并可在后续协作中补齐。
- [ ] 架构事项类型由平台字典维护，事项发布正式结论前必须完成分类。
- [ ] 架构组在七个自然日内完成首次处理，并可选择异步或会议评审方式。
- [ ] 正式结论必须包含理由和行动项；发布后不能原地修改，只能由后续决策替代或部分修订。
- [ ] 当前有效结论及完整替代链可查询，真实 HTTP、MySQL、工作流、附件授权、审计和浏览器旅程通过验收。
