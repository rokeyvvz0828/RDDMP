# 07: 搭建依赖、阻塞与时间控制

Source: ../../spec.md
Spec coverage: User Stories 69-72, 87-91
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 为搭建任务提供显式前置依赖、独立阻塞记录、计划和实际时间、事件更正及逾期标识，使所有状态都能从可追溯事实计算。

**Blocked by:** 06“搭建任务执行与豁免”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 计划责任人能够建立、移除和改绑任务前置依赖，前置未完成时后续任务不能开始并显示等待前置。
- [ ] 前置任务取消不视为完成，后续任务持续等待并提示依赖已取消，直到依赖被处理或任务被取消。
- [ ] 任务支持多条阻塞记录及解除事件；未解除阻塞决定任务阻塞状态并向环节和计划聚合。
- [ ] 计划、环节和任务维护计划时间，实际开始和完成时间由执行事件聚合而不是直接编辑。
- [ ] 有权限人员只能通过附原因的事件更正修正实际时间，原事件、更正记录和重算结果全部保留。
- [ ] 逾期作为独立标识按当前时间、计划结束和取消状态计算，计划时间调整后重算当前逾期并保留历史。
- [ ] 循环依赖、并发状态变化、时间边界、公开 API、真实 MySQL、审计及桌面端和移动端风险展示通过验收。
