# 09: 网络分区与访问关系

Source: ../../spec.md
Spec coverage: User Stories 95-97, 100-107
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 维护层级网络分区和外部网络地址，并让申请人通过两端级联实例选择提交网络访问申请，成功办理后形成一条源实例集合到目标实例集合的访问关系快照。

**Blocked by:** 04“资源下发与环境部署实例”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 网络架构师能够维护分区层级和继承限制，实例单个 IP 只归属一个最具体叶子分区。
- [ ] 网络管理人员能够维护受控外部 IP、网段或域名，并在申请中明确引用。
- [ ] 申请源端和目标端各自只能选择一组物理子系统、具体环境和部署单元，再选择当前实例集合。
- [ ] 实例选择默认全选当前级联结果但允许取消，跨部署单元必须拆单，后续新增实例不自动加入快照。
- [ ] 申请支持协议、多个端口或端口范围、用途和有效期；平台工作流办理成功后才形成访问关系。
- [ ] 一张申请对应一条源集合到目标集合关系，需要限制特定实例对时必须拆分申请。
- [ ] 公开 API、真实 MySQL/Flyway、真实工作流、权限审计和桌面端及移动端申请旅程通过验收。
