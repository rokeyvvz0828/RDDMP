# 08: 搭建计划调整与综合跟踪

Source: ../../spec.md
Spec coverage: User Stories 61-64, 73-74, 92-94
Execution gate: Wayfinder“形成受控实施路线”解决后方可开工

**What to build:** 支持运行中计划调整目标和结构、关联多类工单并执行完成门禁，同时提供可下钻的看板、时间视图、报告、查询和通知。

**Blocked by:** 03“具体环境与资源申请”；06“搭建任务执行与豁免”；07“搭建依赖、阻塞与时间控制”；Wayfinder“形成受控实施路线”（外部门禁）

**Status:** ready-for-agent

- [ ] 计划开始后可附原因新增环节、任务、检查项和目标，新目标使用计划自身模板快照生成任务。
- [ ] 移出目标时未完成任务按规则取消、已完成历史保留；只有从未执行的错误内容可附原因删除。
- [ ] 任务可发起或关联资源及其他符合公开契约的工单，存在未结束工单时不能完成。
- [ ] 工单结束只解除完成门禁，不自动完成任务；业务状态与工单流程状态保持分离。
- [ ] 用户可按环境、责任人、目标、状态、阻塞、逾期和豁免查询并从汇总下钻到检查项和操作历史。
- [ ] 看板、时间视图、报告和通知均复用同一计算事实；通知失败不改变业务状态。
- [ ] 真实跨模块 HTTP 场景、MySQL、工作流、权限审计、桌面端和移动端看板与调整旅程通过验收。
