# 项目概览甘特图

## Objective

优化项目详情的项目概览：移除项目日历，增加主计划月维度甘特图和包含主计划层级的子计划周维度甘特图。

## Scope

- 删除项目概览中的项目日历展示和相关交互。
- 新增主计划甘特图，横轴按月份显示项目计划周期。
- 新增子计划甘特图，横轴按周显示，并在子计划行上方保留对应主计划行作为层级分组。
- 使用现有项目计划数据、ECharts、交付示范中心的甘特图绘制思路和语义主题变量。

## Non-goals

- 不新增后端接口、数据库字段、Flyway 迁移或权限。
- 不改变项目计划的维护、日期校验和进度计算规则。
- 不改造项目计划列表或其他项目详情页签。

## Acceptance criteria

1. 项目概览不再渲染项目日历。
2. 主计划甘特图按月份展示所有有有效日期的主计划，计划条与状态/进度可识别。
3. 子计划甘特图按周展示，主计划位于其子计划上方，层级关系和计划条可识别。
4. 无日期计划显示明确的空状态，不渲染空白图表。
5. 图表在浅色、深色和现有配色下使用语义主题变量，桌面与移动端不产生页面级横向溢出；移动端图表只在自身容器内局部滚动。
6. `npm --prefix web run build` 和 `git diff --check` 通过，真实浏览器验证项目详情概览路径。

## Verification

- 桌面视口打开项目详情概览，确认日历消失、两块甘特图有月份/周刻度和层级。
- 手机视口检查图表局部滚动、文字可读和页面级横向溢出。
- 检查无日期和无子计划数据的空状态。
