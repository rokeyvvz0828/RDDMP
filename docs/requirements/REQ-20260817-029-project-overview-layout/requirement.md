# 项目概览信息与排期布局

## 业务目标

让项目概览先呈现项目与整体计划的统一摘要，再呈现主计划和子计划排期，减少信息分散和排期入口不明显的问题。

## 范围

### 本次实施

- 将项目基本信息与整体计划进度信息合并为一个项目概览信息块。
- 将主计划排期和子计划排期放在计划状态、执行进度图表之前。
- 保留主计划点击选择子计划甘特图的交互和现有主题、局部滚动能力。

### 本次不实施

- 不调整项目数据、接口、权限、数据库或计划计算规则。
- 不改变主计划/子计划甘特图的时间维度和选择逻辑。

## 验收标准

1. 项目基本信息与整体计划信息在同一视觉信息块中展示，且负责人、周期、成员、计划和总体进度均可识别。
2. 主计划和子计划排期区域位于状态分布和执行进度区域之前，页面不发生重叠或横向溢出。
3. 点击主计划仍能加载对应子计划甘特图，刷新、空状态和主题表现不回归。
4. 前端构建和差异检查通过。

## 测试与发布

- 必须执行：`npm --prefix web run build`、`git diff --check`、浏览器项目概览布局和主计划选择验收。
- 回退：恢复本任务对 `ProjectView.vue` 与 `styles.css` 的修改。
