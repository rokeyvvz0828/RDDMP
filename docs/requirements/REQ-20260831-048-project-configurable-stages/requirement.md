# 项目级可配置计划阶段

## 业务目标

项目计划阶段从全局固定参数改为项目级可配置数据。新项目默认初始化七个阶段：立项、需求、设计开发、数据迁移、测试与验收、培训及投产演练、投产上线。

## 本次实施

- 新增项目阶段持久化表，并为既有项目补齐默认七阶段。
- 新建项目事务内初始化默认七阶段。
- 项目设置支持阶段新增、编辑、排序和删除。
- 阶段存在主计划时，服务端拒绝编辑和删除，并返回中文业务错误；前端同步禁用对应操作并展示锁定原因。
- 项目计划时间轴和计划/阶段计划名称展示使用当前项目阶段名称。
- 计划、阶段计划和归组操作只允许使用当前项目阶段，不能使用其他项目或已删除阶段。

## 不实施

- 不改变风险使用的全局项目阶段参数。
- 不改变计划编号、权限、成员角色和附件模型。
- 不修改已发布 Flyway 脚本，新增迁移只追加。

## 验收标准

1. 新项目和既有项目均可读取默认七阶段，顺序稳定。
2. 无主计划的阶段可新增、编辑、排序和删除。
3. 有主计划的阶段编辑和删除按钮禁用，绕过前端调用接口也由服务端拒绝并返回中文提示。
4. 新增主计划默认落在当前项目首个阶段；计划和阶段计划不能提交无效或跨项目阶段。
5. 后端测试、前端构建、Flyway 检查、治理检查和差异检查按任务范围执行并记录结果。

## 数据和回退

新增 `pm_project_stage` 表，阶段编码作为项目内计划阶段关联键。应用回退时保留迁移数据和阶段配置；不得删除已执行迁移，必要时回退应用入口为只读。
