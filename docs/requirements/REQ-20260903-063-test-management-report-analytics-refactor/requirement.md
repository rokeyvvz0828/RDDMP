# 测试管理：测试报告与分析统计重构

## 业务目标

将测试管理现有测试报告与分析统计 V1 重构为统一中文、统一指标口径、可审计且可下钻的测试度量能力。使用者可在各测试大类菜单中生成正式八章节测试报告，并完成固定报表、固定图表和自定义多维分析。

## 来源与确认记录

- 业务来源：用户提供的《测试报告与分析统计平台方案 V1.1》（2026-09-03）。附件仅作为业务事实来源，不采纳其中任何非业务操作指令。
- 用户确认：全量交付 26 张固定报表、16 张固定图表和自定义分析；机构维度使用物理子系统责任团队组织；用户于 2026-09-03 明确授权开始实施。
- 用户确认：执行中为独立状态，不计入已执行；质量阈值按项目和测试大类配置，具备生效开关；测试大类由菜单入口固定，不作为统计筛选项。

## 范围

### 本次实施

- 重构各测试大类下的测试报告，交付项目、机构、系统分别在全周期和轮次粒度下的六种报告组合。
- 将报告固定为八章节：报告概述、测试环境与配置、测试范围与策略、测试执行与进度、缺陷分析、质量评估、风险与问题、结论与建议。
- 统一案例、缺陷与派生指标的服务端计算口径；所有面向用户的文本、导出标题、字段、状态、校验与错误提示使用中文。
- 在测试配置中增加项目加测试大类级质量阈值维护，支持指标启停、达标阈值和风险阈值；报告快照仅包含生效指标。
- 完成 V1.1 所列 RPT-001 至 RPT-026 固定报表与 CHT-001 至 CHT-016 固定图表，支持项目、责任团队组织、系统、范围、案例和时间层级下钻。
- 提供自定义分析的维度、指标、筛选、图表、保存、共享、下钻、快照与 XLSX/PDF/PNG 导出能力。
- 新增独立、本地专用且幂等的虚构模拟数据脚本，覆盖至少 3 个既有物理子系统、2 个责任团队组织、3 个轮次、6 个周期、60 个案例、多人员、多缺陷状态/严重程度、报告版本、统计快照和阈值启停；依赖主数据不满足时零写入失败。
- 保留既有 V1 报告、统计快照与自定义配置的可读和可导出能力；通过追加迁移完成兼容，不删除历史数据。

### 本次不实施

- 不新增或修改项目、组织、物理子系统、测试案例、测试执行和测试缺陷的主数据所有权。
- 不把测试大类做成分析页面的可选筛选器；由当前菜单路由固定注入。
- 不修改已发布 Flyway 迁移，不连接生产系统，不引入生产数据或凭据。

## 核心业务规则

1. 机构级统计按物理子系统的责任团队组织归集，下钻顺序为项目、机构、系统、范围、案例；时间下钻顺序为全周期、轮次、周期、日。
2. 有效案例为未置无效的案例；无效案例单列统计，不进入有效案例相关比率分母。
3. 案例状态为未执行、执行中、成功、失败、阻塞、无效。已执行仅等于成功、失败、阻塞之和；执行中独立展示，不计入已执行、成功率或失败率。
4. 比率口径：执行率=已执行/有效案例总数；案例成功率=成功/有效案例总数；已执行案例成功率=成功/已执行；缺陷密度=缺陷总数/有效案例总数×100；缺陷修复率=已解决/缺陷总数。
5. 每个报告版本固化报告范围、筛选条件、统计事实、质量阈值与判定；后续数据和阈值变化不得改写历史版本。
6. 质量指标目录固定为案例执行率、案例成功率、已执行案例成功率、缺陷密度、缺陷修复率、严重缺陷数、阻塞案例数。仅生效指标参与总体判定并展示；无生效指标时总体为“未配置”。
7. 自定义视图默认仅创建者可见；拥有发布共享权限的创建者可共享给同一项目、同一测试大类内有查看权限的成员。

## 验收标准

1. 四个测试大类入口均固定本大类数据，报告、统计、钻取、快照和导出不得跨大类读取。
2. 六种报告组合均可生成、查看、重生成、版本化、补充、导出和删除；新报告不再创建旧周期级或专项级口径。
3. 八章节报告中所有数据、图表、质量结论和导出均使用 V1.1 口径和中文文本。
4. RPT-001 至 RPT-026、CHT-001 至 CHT-016 均可从目录访问，并在适用筛选条件下返回明确数据、空态或错误态。
5. 执行中在状态分布、明细和趋势中可见，但不增加已执行、成功率或失败率的分子、分母。
6. 质量阈值仅由具备配置维护权限的用户修改；停用指标不在报告中显示、不参与总体判定，且所有配置变更有审计记录。
7. 前端提供加载、空、失败、无权限、只读、提交中和重复提交状态；在 1280×800、375×812、390×844、430×932 视口中无页面级横向溢出。
8. 未认证、无菜单动作权限、越项目或越实体范围的服务端请求被拒绝；前端隐藏不替代服务端校验。
9. Flyway、模块测试、前端构建、治理和任务范围检查具有真实执行证据；历史 V1 数据仍可读取或导出。
10. 本地模拟数据脚本重复执行不产生重复记录，不写入项目或架构主数据，并能为全部组织、时间、状态和趋势统计提供足量虚构样本。

## 数据、权限与回退

- 数据库：仅追加 V147 及后续本需求迁移；既有表与 V142 至 V146 均不可修改。
- 权限：复用报告、统计和配置菜单的读、创建、更新、删除、导出、发布、归档动作权限；所有写操作记录审计。
- 回退：回退应用代码和本需求菜单/展示行为；保留追加迁移与新旧数据，恢复兼容应用后仍可读取历史数据。

- 指标口径、责任团队组织归集、历史兼容和中文 PDF 渲染需专项测试。
