# 数据迁移「迁移参数」字段信息子表与批量导入优化

## 业务目标

在「数据迁移 › 数迁资产内容 › 迁移参数」（菜单 752）为每个迁移参数增加字段信息子表，记录参数的
字段英文名、字段中文名、字段类型、字段长度与字段说明；同一参数内字段英文名、字段中文名均不允许重复。
前端在参数新增/编辑流程中支持批量添加字段，并提供字段维护入口；批量导入参数时可在同一 Excel 中同时
导入各参数对应的字段信息。

## 范围

### 本次实施

- 新增 `dm_parameter_field` 子表，`parameter_id` 关联 `dm_parameter`，含字段英文名、字段中文名、
  字段类型、字段长度、字段说明与排序号；同参数内中英文名唯一（软删行不占用名称，对标目标表字段范式）。
- 新增「参数字段类型」系统参数码值 `DM_PARAMETER_FIELD_TYPE`，统一由系统管理/参数管理维护。
- 后端扩展 `ParameterService` / `ParameterController`：参数详情返回字段列表；新增参数支持携带 `fields`
  批量创建；新增字段列表、批量新增、单条编辑、删除、批量删除接口。
- 前端 `ParametersPage.vue`：新增/编辑流程支持批量添加字段行；参数列表行「字段」入口维护字段
  （列表、批量新增、行编辑、批量删除）；详情弹层展示字段清单；导入弹层与模板支持「参数+字段」同文件导入。
- Excel 模板从六列扩展为十一列：参数类型、参数范围分类、系统编号、参数名称、参数英文名、参数说明、
  字段英文名、字段中文名、字段类型、字段长度、字段说明；每行一个字段，同一参数的字段行连续排列、
  参数信息整组重复；字段列留空即兼容原六列纯参数导入。
- 参数逻辑删除时字段级联软删，恢复时一并恢复，彻底删除时级联物理删除。

### 本次不实施

- 不新增/改造「系统管理/参数管理」页面本身（码值由该系统维护）。
- 不改变其他内容类型（迁移方案/检核规则/映射/依赖关系等）既有行为。
- 不引入新的公共组件或新样式体系；复用 `UiDataTable`/`UiFormDrawer`/`UiEmptyState` 等既有能力。
- 参数导出保持参数级八列，不展开字段明细。

## 现状与规则

- 当前入口：`/data-migration/content/parameters`，菜单 752；权限节点 `data-migration:content:parameters`
  及 `:create/:update/:delete` 已存在，本需求不新增权限码。
- 数据来源：所属项目取全局项目上下文；字段类型取系统管理/参数管理 `DM_PARAMETER_FIELD_TYPE` 码值。
- 字段英文名必填、不允许空格、仅允许字母数字下划线、长度不超过 128；字段中文名必填、不允许空格、
  长度不超过 128；`abc_01` 与 `ABC_01` 视为同名字段。
- 字段类型必填且必须为启用的 `DM_PARAMETER_FIELD_TYPE` 码值；字段长度为可选正整数；字段说明可选、
  不超过 500 字符。
- 同一参数内字段英文名唯一、字段中文名唯一，应用校验 + 数据库唯一键双保险；软删字段行不占用名称。
- Excel 导入：参数维度仍按原规则逐行校验（类型/范围码值、系统归属、名称/英文名唯一等）；同一参数
  （系统编号 + 参数名称）连续多行归为一个参数组并累加字段；组内字段中英文名唯一；字段列全空视为纯参数行；
  整行全空跳过；与组首行参数信息不一致的非空列按行报错。
- 角色权限：统一平台 RBAC，不硬编码角色。
- 审计：参数写入沿用 `dm_operation_log`（`entity_type='PARAMETER'`）；字段写操作记录
  `FIELD_CREATE/FIELD_UPDATE/FIELD_DELETE`，`entity_type='PARAMETER'`、`entity_id` 记参数 id。

## 接口与数据

- 复用接口：`GET /api/data-migration/components/options/systems`、`GET /api/data-migration/options/{category}`、
  统一回收站 `/api/data-migration/recycle-bin`。
- 新建接口（挂在 `/api/data-migration/parameters` 下，沿用参数写权限码）：
  - `GET /{id}/fields` 字段列表
  - `POST /{id}/fields` 批量新增字段（JSON 数组）
  - `PUT /{id}/fields/{fieldId}` 编辑字段
  - `DELETE /{id}/fields/{fieldId}` 删除字段
  - `POST /{id}/fields/batch-delete` 批量删除字段（JSON 数组）
- `POST /api/data-migration/parameters`（新增）允许携带可选 `fields` 数组批量创建字段。
- 数据 Owner：business/data-migration。
- 数据库迁移：追加 `V200__data_migration_parameter_field.sql`，不修改已发布脚本；建表与码值均幂等。
- 脱敏示例：字段名称/说明仅使用本地虚构数据，不包含真实个人信息或生产数据。

## 验收标准

1. 参数列表行提供「字段」入口与字段数展示；字段维护抽屉可列表、批量新增、行编辑、删除与批量删除字段；
   详情弹层展示字段清单（英文名/中文名/类型/长度/说明）。
2. 新增参数弹窗可批量添加字段行；必填项缺失/非法（空英文名、空中文名、空类型、非法字符、长度非法）阻断并提示；
   同一参数内字段英文名重复、字段中文名重复被拒绝（应用与数据库双层）。
3. 导入模板为十一列；单文件同时导入参数及其字段，字段列留空仍可导入纯参数；失败行跳过并逐行报错；
   成功参数及字段自动回填上传人/上传时间与操作日志，导出文件保持参数级八列。
4. 参数逻辑删除后详情/列表不再展示字段；回收站恢复参数时字段一并恢复；彻底删除参数时字段级联删除。
5. 前端覆盖加载/空/失败/无权限/提交中/重复提交状态；桌面与 375/390/430 移动视口无横向溢出。
6. 权限遵循既有菜单 RBAC，写操作后端强制校验；字段写操作保留审计。
