# 项目概览甘特图选择交互

## Objective

重新组织项目概览排期区域：主计划甘特图作为入口，用户点击选中的主计划后，才加载该主计划的子计划甘特图。

## Scope

- 将项目概览排期区域改为主计划甘特图和子计划详情区的上下布局。
- 主计划甘特图的计划条可点击，并以选中状态反馈当前主计划。
- 子计划甘特图只展示当前选中主计划及其子计划；切换主计划时刷新下方图表。
- 未选择主计划时展示明确引导；选中但无有效子计划时展示空状态。

## Non-goals

- 不新增后端接口、数据库字段、Flyway 迁移或权限。
- 不改变项目计划数据、层级关系、日期校验和进度规则。

## Acceptance criteria

1. 项目概览排期布局清晰，主计划图在上，子计划区域在下，其他概览信息不与图表重叠。
2. 点击主计划甘特图中的计划条后，子计划甘特图只展示该主计划的子计划，并保留主计划行作为上下文。
3. 切换另一个主计划后，下方图表内容随之切换；未选择时不展示全部子计划。
4. 图表选中状态、空状态和当前主计划名称清晰可见，主题和局部滚动规则保持不变。
5. 前端构建、差异检查和真实浏览器交互验收通过。
