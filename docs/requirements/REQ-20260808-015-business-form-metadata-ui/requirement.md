# REQ-20260808-015 业务表单输入项配置入口

status: ready

## 目标

为上一需求建立的业务表单元数据模型补齐系统设置前端入口，使管理员可以维护业务范围、表单分区、输入项属性、条件规则和静态选项，并发布可追溯的配置版本。

## 实施范围

- 在系统管理菜单下新增“输入项配置”。
- 新增受权限保护的表单元数据查询、保存、删除和发布 API。
- 新增 Vue 3 配置页面，复用系统设置和交付示范中心的页面、表格、抽屉和语义主题模式。
- 新增菜单和权限 Flyway 迁移，不修改既有业务表和既有业务页面。

## 非目标

- 本需求不把现有业务页面改造成动态表单。
- 本需求不替换业务主表、不修改 Java 包名、不改变既有业务逻辑。
- 本需求不允许前端绕过后端权限、状态规则或字段白名单。

## 验收标准

- 登录后具备 `system:form-config:list` 权限的用户能从系统管理进入“输入项配置”。
- 页面可以新增/编辑业务范围、分区、字段，并维护字段显示、列表、筛选、布局、规则和静态选项。
- 发布操作生成配置版本并更新当前发布版本；服务端拒绝非法字段类型、跨范围分区和未经授权操作。
- 页面覆盖加载、空数据、失败、保存中、只读无权限和移动端重排状态。
- JDK 17 后端测试、前端构建、治理和 Flyway 检查通过。

## 回退

停用新增菜单或回退应用版本即可停止使用配置入口；新增表和配置版本按数据库回退规约保留，不手工删除生产数据。
