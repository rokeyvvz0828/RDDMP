# 数据迁移「迁移参数」菜单功能优化

## 业务目标

将「数据迁移 › 数迁资产内容 › 迁移参数」（菜单 752）从通用结构化资产薄页面升级为迁移参数专属管理页，
统一管理业务参数、技术参数两类迁移配置参数，覆盖单条/批量录入、Excel 模板批量导入、编辑、
逻辑删除与统一回收站，并支持按项目、参数类型、参数范围分类、关联系统/组件及关键字多维筛选与分页展示。
交互与实现对齐「迁移方案 / 迁移检核规则」已验证的域化范式。

## 范围

### 本次实施

- `dm_parameter` 域化改造：新增参数类型/参数范围分类/关联系统/参数名称/参数英文名/参数说明业务列，保留逻辑删除字段。
- 新增「参数类型」「参数范围分类」系统参数码值（业务参数/技术参数、公共参数/自有参数），统一由系统管理/参数管理维护。
- 新增 `ParameterService` / `ParameterController` / `ParameterRecycleBinSource`，收口参数专属 REST 与回收站。
- 前端 `ParametersPage.vue` 升级为专属页：多维筛选、分页、单条录入/编辑、Excel 模板导入、条件导出、逻辑删除。
- 复用统一回收站（`PARAMETER` 类型由新来源承接）。

### 本次不实施

- 不新增/改造「系统管理/参数管理」页面本身（码值由该系统维护）。
- 不改变其他内容类型（迁移方案/检核规则/映射等）既有行为。
- 不引入新的公共组件或新样式体系。

## 现状与规则

- 当前入口：`/data-migration/content/parameters`，菜单 752；权限节点 `data-migration:content:parameters` 及
  `:create/:update/:delete` 已存在（V190 已登记），本需求不新增权限码。
- 数据来源：所属项目取全局项目上下文（页面不提供项目下拉）；关联系统下拉复用 `/components/options/systems`
  （当前项目启用 `dm_component`）；参数类型/范围取系统管理/参数管理码值。
- 唯一约束（用户已确认）：`租户 + 项目 + 系统编号` 内参数名称唯一；参数英文名在同一范围内不区分大小写唯一。
- 参数英文名必填，只允许字母、数字和下划线，长度不超过 255 字符；`ABC_01` 与 `abc_01` 视为重复。
- Excel 模板列（用户已确认）：参数类型、参数范围分类、系统编号、参数名称、参数英文名、参数说明；维度逐行填写并逐行校验。
- 角色权限：统一平台 RBAC，不硬编码角色。
- 审计：写入 `dm_operation_log`，`entity_type='PARAMETER'`；上传/删除时间与人员由系统回填。

## 接口与数据

- 复用接口：`GET /api/data-migration/components/options/systems`、`GET /api/data-migration/options/{category}`、
  统一回收站 `/api/data-migration/recycle-bin`。
- 新建接口：`/api/data-migration/parameters` 的列表/详情/新增/编辑/删除、模板下载、导入、导出。
- 数据 Owner：business/data-migration。
- 数据库迁移：保留已发布的 `V197__data_migration_parameter_domain.sql`，追加 `V198__data_migration_parameter_english_name.sql`，不处理已有数据且不改历史脚本；若迁移时存在参数记录则失败关闭。
- 脱敏示例：参数名称/说明仅使用本地虚构数据，不包含真实个人信息或生产数据。

## 验收标准

1. 迁移参数页可按参数类型/参数范围分类/关联系统/关键字筛选并分页展示，字段含 项目名称、参数类型、
   参数范围分类、系统编号、系统名称、参数名称、参数英文名、参数说明、操作；关键字同时匹配参数名称、参数英文名和参数说明。
2. 单条新增/编辑：必填项（所属项目、参数类型、参数范围分类、关联系统、参数名称、参数英文名）缺失或非法时阻断并提示；
   参数名称在同 租户+项目+系统编号 内唯一，参数英文名在同一范围内不区分大小写唯一且只允许字母、数字和下划线。
3. Excel 批量导入：模板逐行解析参数英文名并执行必填、字符集和不区分大小写唯一校验；失败行跳过并逐行报错；成功后自动回填上传人/上传时间与操作日志。导出文件包含参数英文名。
4. 删除为逻辑删除，进入统一回收站；回收站支持恢复与彻底删除，恢复时参数名称唯一冲突阻断。
5. 前端覆盖加载/空/失败/无权限/提交中/重复提交状态；桌面与 375/390/430 移动视口无横向溢出。
6. 权限遵循既有菜单 RBAC，无硬编码角色；写操作后端强制校验。
