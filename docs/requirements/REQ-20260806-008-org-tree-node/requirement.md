# 组织树节点信息优化

## 目标

优化组织架构页面左侧组织节点的信息层级和操作密度，保证组织名称可读，并让节点操作含义清晰。

## 实施范围

- 节点第一行展示完整组织名称，第二行展示成员数和启停状态。
- “新增下级组织”保留为节点快捷操作。
- 添加用户、编辑组织和删除组织收纳到文字化更多菜单。
- 组件示例与组织管理页共用同一展示和交互。

## 非实施范围

- 不修改组织、用户接口及数据结构。
- 不修改新增、编辑、删除和添加用户的原有业务逻辑。
- 不调整组织成员表格和组织筛选规则。

## 验收

1. 组织名称不再被成员数和操作图标挤压成单字或异常省略。
2. 成员数和启停状态位于次级信息行，当前节点仍可辨识。
3. 新增下级组织、添加用户、编辑和删除事件均保持可用。
4. 组织树在桌面窄栏和移动单栏下无横向溢出，明暗主题可读。

## 回退

回退 `UiOrgTree.vue` 节点模板和对应样式，不影响组织数据及接口。
