# 项目管理演示数据

## 业务目标

为本地研发环境补充可直接展示的项目管理演示数据，使项目工作台能够查看多个项目、主计划/子计划、项目成员、项目角色和计划组织关系，并覆盖不同状态与进度。

## 范围

### 本次实施

- 扩展本地 mock 数据字段白名单，允许项目主表、计划、成员、角色及关联表同步。
- 在 `mock/mock-data.json` 增加两个脱敏项目及其关联数据。
- 使用现有 mock 用户、组织和租户 1，覆盖计划状态、计划进度、计划日期和项目角色。

### 本次不实施

- 不修改项目 API、项目服务、数据库表结构或 Flyway 迁移。
- 不修改生产配置、真实用户数据、密码、Token、密钥或外部服务。

## 现状与规则

- 数据来源：`mock/mock-data.json`，仅在 `local` profile 且 `MOCK_DATA_ENABLED=true` 时启动同步。
- 数据同步：按表白名单进行幂等 upsert，使用高位 mock ID。
- 计划规则：主计划编号使用项目规则，子计划编号扩展父计划编号；子计划日期必须落在父计划日期范围内。
- 关联关系：所有行保留 `tenant_id`；成员、角色和组织关系引用现有本地 mock 数据。

## 验收标准

1. mock 数据 JSON 可解析，新增表均通过同步器白名单校验。
2. 后端重启日志显示 mock 数据同步成功，项目接口返回至少两个项目和计划树数据。
3. 项目详情包含成员、角色、主计划、子计划及牵头/配合组织关系。

## 测试与发布

- 执行 JSON 解析、Maven 打包、后端重启和项目 API 查询验证。
- 仅用于本地演示；回退方式为恢复本轮 mock 数据和白名单修改后重启本地后端。
