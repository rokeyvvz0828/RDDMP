# 项目资产导入导出与统一管理界面

## 业务目标

为数据迁移项目资产提供普通上传/下载、带清单的迁移包导入/导出和桌面/移动统一管理界面，使用户可以在一个工作入口完成查询、目录、上传、下载、更新、删除、预览、分享、收藏、标签、备注、审核和回收站操作。

## 范围

### 本次实施

- 提供普通单个/批量导入和单文件下载、批量 ZIP 导出。
- 提供 ZIP64 迁移包导出，包含文件、目录、标签、追加备注和 `manifest.json` 摘要清单。
- 提供迁移包上传、校验、冲突预览、执行、进度、部分失败、重试和结果报告。
- 导入文件重新执行病毒扫描并进入草稿；不继承收藏、分享令牌或既有审批结论。
- 新增 `web/src/modules/data-migration` 统一资产管理页面和独立 API 封装。
- 桌面采用项目选择、目录树、查询工具栏、资产表格、详情抽屉和批量操作；移动端采用目录抽屉、文件卡片和底部操作层。
- 提供全部文件、我的收藏、待我审核、传输任务和回收站视图，以及持续可见的上传/传输进度。
- 支持桌面拖拽上传和拖拽换目录，同时提供键盘、触屏可用的文件选择和移动目录对话框。

### 本次不实施

- 不实现跨租户迁移、外部对象存储直连、全文检索、OCR、在线编辑或永久匿名分享。
- 不把迁移包作为数据库备份，不导入项目成员、平台角色、分享凭据或审计日志。
- 不修改公共 UI 组件行为；资产专项样式仅覆盖目录、文件单元格和上传队列。

## 现状与规则

- 依赖 `REQ-20260818-026`、`REQ-20260818-027` 和 `REQ-20260818-028` 已达到可集成状态。
- 普通语义为导入即上传、导出即下载；迁移包提供结构和元数据迁移。
- UUID 冲突时生成新 UUID 并记录映射；同目录路径合并；单文件失败不回滚其他成功文件。
- 单批最多 1,000 个文件，批量导入导出均使用异步任务；大文件和 ZIP64 全程流式处理。
- 页面优先复用交付示范中心、`UiToolbar`、`UiDataTable`、`UiEmptyState`、`UiFilePreview`、现有树模式和语义主题变量。

## 接口与数据

- API 包括普通批量导入、单文件下载、批量 ZIP 导出、迁移包导出任务、迁移包上传/校验/执行、任务状态和结果报告。
- 传输任务记录类型、状态、总数、成功数、失败数、进度、发起人、结果附件和错误报告。
- `manifest.json` 记录目录、文件 UUID、相对路径、大小、类型、MD5、SHA-256、标签和备注；导入不信任清单中的权限、审核或上传人。
- 迁移包限制文件数、展开大小、压缩比和目录深度，阻止路径穿越、压缩炸弹和无界资源消耗。
- 前端项目选择来自正式 Project Context Store，页面不得硬编码项目数组或把选择结果当作后端授权依据。

## 验收标准

1. 单个/批量上传、单文件下载和批量 ZIP 导出可完成并提供逐项结果。
2. 迁移包导出包含完整文件、目录、标签、备注和可校验清单，不包含收藏、分享或审批结论。
3. 导入能预检冲突、报告 UUID 映射和部分失败，成功文件重新扫描并进入草稿。
4. 统一页面支持需求列出的查询、下载、删除、更新、导入导出、预览、分享、收藏、标签、备注、审核和回收站操作。
5. 页面覆盖加载、空、失败、无权限、归档只读、上传中、扫描中、隔离、审核中、部分成功和重复提交状态。
6. 桌面、`375x812`、`390x844`、`430x932`、浅色和深色主题无页面级横向溢出，关键操作可达。
7. 单租户 100 万文件、单项目 10 万文件、1 万目录和 1,000 文件批量任务基线下满足已确认性能指标。
8. 全量 Maven、前端构建、治理、运行健康检查和真实浏览器用户路径通过。

## 测试与发布

- 必须执行传输任务/清单/ZIP 安全测试、API/权限/部分失败测试、`mvn test`、`npm --prefix web run build`、治理和任务范围检查。
- 启动 MySQL、MinIO、ClamAV、kkFileView、后端和前端，验收桌面和三个手机视口、明暗主题、控制台及网络错误。
- 回退时关闭资产菜单、导入导出和传输任务调度，保留任务结果、清单、资产和对象数据，不执行生产 `DROP` 或自动对象清理。
- 风险包括大型 ZIP 资源消耗、部分失败恢复、移动端批量交互和跨需求集成；需 data-migration、frontend、security 和 infrastructure Owner 复核。
