# 投产基线维护时间限制

## 业务目标

投产管理人员可以随时查看各投产窗口的基线明细，但只有当前时间达到该窗口的投产结束时间后，才允许维护单条或批量投产结果，避免在窗口尚未结束时提前确认最终结果。

## 必须行为

1. 投产基线的窗口下拉项展示窗口编码、名称、状态、投产结束时间和不可维护原因。
2. 未到投产结束时间的窗口仍可选择并查看基线数据。
3. 选中未结束窗口时，禁用行选择、单条维护和批量维护，并在页面明确说明预计开放时间。
4. 当前时间达到 `productionEnd` 时允许维护，不要求窗口状态已切换为 `CLOSED`。
5. 单条和批量投产结果接口均按基线明细所属窗口执行相同服务端时间校验。
6. 规则统一适用于常规、紧急和应急版本。

## 非目标

- 不禁止查看未结束窗口的基线数据。
- 不修改投产窗口状态算法、投产结束时间或版本归窗规则。
- 不新增数据库字段、迁移或公开 API 数据结构。
- 不改变已维护结果不可重复维护、乐观锁和审计规则。

## 验收标准

1. 未结束窗口下拉项可被选中，并显示“不可维护”原因及结束时间。
2. 选中未结束窗口后，表格正常展示，但勾选框和维护入口不可操作。
3. 到达结束时间后，前端无需重新登录即可在定时刷新后开放维护。
4. 直接调用单条或批量接口提前维护时，后端返回冲突错误且不写入结果或审计日志。
5. 到达结束时间边界时，单条和批量维护按原规则成功执行。
6. 前端生产构建、发布模块测试、浏览器交互和范围检查完成。

## 回退

回退投产基线页面的时间提示与禁用逻辑，以及投产结果服务的窗口时间校验和对应测试；不涉及数据补偿或数据库回滚。
