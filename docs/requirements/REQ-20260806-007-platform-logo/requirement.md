# 工作台平台标识

## 目标

在应用导航顶部展示统一的平台 Logo 和“工程交付平台”名称，使用户进入工作台后能够快速识别当前平台，并与登录页品牌保持一致。

## 实施范围

- 复用登录页的 `EP` 品牌标识，不引入新的图片或第三方资源。
- 在侧边导航顶部展示完整平台标识，折叠时只保留方形 Logo。
- 在顶部导航和混合导航布局中展示同一平台标识。
- 点击平台标识返回工作台。

## 非实施范围

- 不调整菜单、路由、权限和业务页面。
- 不修改登录页现有文案和品牌视觉。
- 不增加后端接口、数据库结构或外部资源。

## 验收

1. 侧边导航展开时，工作台菜单上方显示 Logo、平台中文名和英文副标题。
2. 侧边导航折叠时只显示 Logo，菜单图标保持居中且不溢出。
3. 顶部导航和移动视口显示紧凑 Logo，点击后进入 `/dashboard`。
4. 明暗主题下标识清晰，前端生产构建和治理检查通过。

## 回退

移除 `AppLayout.vue` 中品牌入口并回退对应样式，不影响菜单路由和业务数据。
