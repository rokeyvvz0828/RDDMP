# Workflow 演示数据

## 目标

为本地 workflow 功能提供可直接查看和验证的演示数据，覆盖流程定义、草稿、运行中实例、已通过实例、已拒绝实例、审批待办、流程已办和监控时间线。

## 范围

- 追加 Flyway V30__seed_workflow_demo_data.sql。
- 所有演示编码使用 DEMO_ 前缀，ID 使用独立高位区间。
- 不修改既有业务数据、用户权限和原有流程定义。
- 演示账号使用现有本地管理员账号 admin。
