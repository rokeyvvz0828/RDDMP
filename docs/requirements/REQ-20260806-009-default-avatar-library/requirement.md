# 工程内置默认卡通头像库

## 目标

在用户新建和编辑表单中提供工程内置的卡通头像选择，减少对用户上传头像文件的依赖，同时保留上传图片作为备用入口。

## 实施范围

- 在前端静态资源中提供一组本地 PNG 卡通头像。
- 在共享头像组件中提供头像库弹层、选中态和可访问名称。
- 选择默认头像后转换为普通 PNG 文件，继续调用现有用户头像上传接口。
- 在窄屏下保持头像库可见且页面无横向溢出。

## 非实施范围

- 不修改用户表结构、头像对象字段或头像上传接口。
- 不引入外部头像服务、远程图片地址或第三方素材依赖。
- 不取消原有本地图片上传能力。

## 验收

1. 用户表单可以打开默认头像库并展示八个本地卡通头像。
2. 选择默认头像后立即展示选中图片，并能复用现有头像上传接口保存。
3. 原有上传图片入口仍可用，头像格式和大小校验保持不变。
4. 桌面和 390px 移动视口下头像选择器无横向溢出，浏览器控制台无错误。
5. 前端构建和治理检查通过。

## 回退

移除默认头像注册表、头像库样式和静态 PNG 资源，保留原有上传图片入口。
