# 项目计划与组织架构调整

## 目标

优化项目详情页的阶段计划入口，并将项目成员和项目角色统一收纳到“项目组织架构”页签。

## 必须需求

- R1：项目计划页右上角移除“分组维护”和“新建分组”按钮。
- R2：用户界面将“计划分组”统一更名为“阶段计划”。
- R3：主计划甘特图区域提供“新增阶段计划”，阶段计划图区域提供“新增主计划”。
- R4：阶段计划不填写名称，使用阶段序号-阶段内序号生成编号，同一阶段依次为 `1-1`、`1-2`。
- R5：新增“项目组织架构”页签，合并原项目成员和项目角色内容，保留原有权限、数据和操作。
- R6：阶段计划编号在服务端生成并保证同一项目、同一阶段下并发创建不重复。

## 约束与验收

- 保持现有中文界面、项目权限和前后端分离契约。
- Flyway 仅追加迁移，不修改已发布脚本。
- 桌面和 375px 手机视口不得出现页面级横向溢出。
- 验收包含前端构建、后端项目测试、迁移检查、范围检查和服务健康检查。
