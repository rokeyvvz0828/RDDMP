# kkFileView 文件预览基础能力

## 目标

在现有平台基础能力中接入 kkFileView，为后续业务模块提供统一、受控的文件在线预览组件和后端适配能力，并在“组件示例”页面提供可操作的上传预览示例。

## 实施范围

- kkFileView 以独立容器运行，固定使用官方稳定版本，不复制第三方源码到主工程。
- 新增 `server/src/platform/file-preview` Maven 平台模块，复用 MinIO 上传和预签名 URL 能力。
- 新增受认证保护的临时文件上传、预览地址生成和删除接口。
- 仅允许配置白名单内的常用文档、图片和文本文件，校验空文件、大小、扩展名和预览源协议/主机。
- 新增前端公共文件预览弹窗和 API 封装，在现有 `/components` 组件示例页演示上传、加载、成功、失败和关闭状态。
- 更新模块清单、架构、CODEOWNERS、Docker Compose、示例环境变量、README 和前端公共组件契约。

## 非实施范围

- 不将 kkFileView 源码并入 Spring Boot 工程，不修改 kkFileView 内部逻辑。
- 不新增业务表、菜单或 Flyway 迁移，不调整现有菜单与路由结构。
- 不允许客户端提交任意外部 URL，不开放匿名上传，不接触生产文件或真实附件。
- 不实现业务附件元数据、版本管理、全文检索和长期文件生命周期管理。

## 验收

1. Maven 模块边界和全量后端测试通过，文件 URL 编码、来源限制、扩展名、大小和删除键校验有自动化测试。
2. 前端生产构建通过，`UiFilePreview` 可在桌面和移动视口内展示加载、预览和失败状态。
3. Docker Compose 可启动固定版本 kkFileView，服务地址、可信来源、上传限制和 MinIO 参数均来自环境变量。
4. 登录后访问“组件示例”，可上传允许类型文件并打开 kkFileView 预览；不允许类型和超限文件得到明确提示。
5. 未配置或未启动预览服务时，原有平台仍可启动，组件示例页给出可恢复的错误提示。

## 回退

移除 `platform/file-preview` 模块、boot 装配、前端公共组件和示例入口，恢复 Docker、环境示例、模块清单及文档；删除 MinIO 中 `file-preview/` 前缀的临时测试对象，无数据库补偿。
