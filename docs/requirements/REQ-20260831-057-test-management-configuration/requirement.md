# 测试管理：管理配置、公告板、方案、范围、案例、执行、缺陷、报告与统计

## 业务目标

让测试管理和机构负责人能在四大测试大类内完成参测系统、系统级测试角色、测试轮次/周期和业务字典配置；后续公告、方案、范围、案例、执行、缺陷、报告与统计模块均从这些配置读取有效范围和选项。

## 范围

### 本次实施

- 在现有测试管理菜单的四个测试大类下增加“管理配置”入口，提供参测系统、角色、轮次与周期、数据字典四个页面。
- 在每个测试大类的默认“公告板”入口交付项目级公告阅读与管理能力：当前公告和公告管理双 TAB、富文本正文、内嵌图片、附件、置顶、检索、分页、发布、编辑和不可恢复删除。
- 在每个测试大类的“测试方案”入口交付按项目级、系统级和专项级节点归类的版本化方案管理：节点树、当前方案预览、上传、版本历史、下载、软删除与操作审计。
- 在每个测试大类的“测试范围”入口交付参测系统下独立范围目录、范围 CRUD、置无效、范围编号联动、XLSX 原子导入/导出、列设置与审计能力。
- 在每个测试大类的“测试案例”入口交付独立案例目录、案例 CRUD、案例编号联动、富文本内容、案例附件、核算核对、批量调整、XLSX 原子导入/导出、列设置与审计能力。
- 在每个测试大类下新增“测试执行”菜单，交付只读轮次/周期树、执行目录、三种案例预览导入、执行详情、批量处理、执行附件、失败必关联缺陷、执行轨迹与导出能力。
- 在每个测试大类下交付“测试缺陷”的列表、新增、详情页面，支持完整字段、快捷筛选、平级执行关联、状态机、附件、审计轨迹、受保护删除和恢复。
- 在每个测试大类下新增“测试报告”菜单，交付项目/系统树、三步生成向导、不可变事实快照版本、章节富文本补充、历史版本、Word/PDF 导出与不可恢复删除。
- 在每个测试大类下新增“分析统计”菜单，交付预置报表、个人/共享自定义报表、筛选、钻取、图表/表格、XLSX/图片导出、轮次统计快照、跨轮次对比及到报告生成的上下文联动。
- 使用“大类 + 项目 + 物理子系统”隔离配置；项目和物理子系统只读引用现有平台数据。
- 临时规则：每个项目都展示所有启用的物理子系统；参测开关决定该子系统是否可用于测试管理。架构模块提供项目—子系统关系后再替换候选列表来源。
- 支持参测系统与角色的 XLSX 模板导入、全量预校验和原子导入；支持轮次/周期 CRUD 与排序；支持字典选项维护、停用与引用保护。
- 新增服务端 RBAC、租户/实体范围校验和操作审计；所有新增表使用追加 Flyway 迁移。

### 本次不实施

- 不维护项目、用户或物理子系统主数据，不新增项目—子系统主数据关系。
- 不实现独立回收站菜单、通知中心与全局项目选择器；后续需求逐模块实施。
- 不更改现有营业日管理行为或其数据表。

## 现状与规则

- `business/test-management` 已注册，当前只有营业日管理持久化；四大测试大类下的领域页面是会话级占位 CRUD。
- 平台项目、用户与物理子系统为只读数据源。物理子系统暂不与项目建立主数据关系。
- 配置数据必须按测试大类隔离；写操作必须在服务端验证调用者权限、租户和当前项目/系统关系。
- 模板导入先模拟校验；任意行错误时不得写入。单元格为空不用于清空存量值。
- 轮次结束只改变状态，不联动生成报告或统计快照；有执行数据或快照时，删除由后续模块的引用检查保护。
- 公告板按“测试大类 + 项目”隔离，项目内所有系统共用；页面只消费现有全局项目上下文，未选项目时不请求数据并显示“请先选择项目”。
- 当前公告向所有具备公告阅读权限的角色开放；公告管理及发布、编辑、置顶、删除仅向测试经理及以上的服务端菜单权限开放，测试人员和开发人员不显示管理 TAB。
- 2026-09-01 范围扩展以用户确认的《测试管理平台详细需求规格说明书（V1.6）》模块 6、模块 7 和“测试管理demo.html”为执行、缺陷的业务规格。执行和缺陷均按“大类 + 项目 + 物理子系统”隔离，且只消费现有全局项目上下文；测试环境只读引用现有测试管理环境数据。
- 2026-09-01 范围再次扩展，以用户提供的《测试管理平台详细需求规格说明书（V1.6）》模块 8、模块 9 与“测试管理demo.html”为测试报告和分析统计业务规格。报告与统计均只消费现有全局项目上下文；物理子系统只显示名称，页面复用测试范围的紧凑树、通用可调列宽列表和居中弹窗。
- 当前公告展示全部置顶公告（按置顶时间倒序）；无置顶时展示最新公告；无公告时显示“暂无公告”，且仅管理者可见“发布第一条公告”。公告没有有效期。
- 公告标题最多 100 字且正文必填。正文使用受限富文本，允许加粗、斜体、段落、列表、表格、链接及引用已上传的内嵌图片；服务端净化 HTML，禁止脚本和事件属性。
- 附件单文件最大 50MB，数量不限；编辑可新增和移除附件；删除公告级联删除已绑定附件且不可恢复。编辑保留首次发布时间并记录最后编辑人和时间；所有写操作记录操作审计。

## 接口与数据

- API：`/api/test-management/configuration/**`，统一返回 `ApiResponse`。
- 数据 Owner：测试管理模块拥有参测映射、系统角色、轮次、周期、字典、执行与缺陷；项目、用户、物理子系统由既有模块拥有。
- 数据库：追加 `V123__test_management_configuration.sql` 至 `V127__test_management_execution_defect.sql`，不得修改已发布迁移。应用回退时保留新增配置数据，不删除迁移。
- 数据库：报告和统计数据仅通过追加 `V128__test_management_report_analytics.sql` 创建，不修改已发布迁移。报告事实快照和历史版本由测试管理模块独占；删除报告时级联物理删除版本与补充内容。
- 输入输出只使用本地虚构测试数据；不读取生产系统或密钥。

## 验收标准

1. 管理配置入口只对具备服务端配置权限的用户可访问；绕过前端仍由接口拒绝未授权请求。
2. 参测系统页按当前大类和项目展示全部启用物理子系统，开关变更后可重复读取；取消参测前返回受影响业务数据计数并要求确认。
3. 角色只能分配给已参测系统；同一用户在同一系统可拥有多个角色，移除时返回未完成缺陷和最后执行记录提示计数。
4. 轮次和周期名称在各自父级唯一，日期合法；周期可越出轮次日期但返回非阻断提醒；排序持久化，结束轮次不创建其他数据。
5. 本地字典支持新增、编辑、启停和排序；被引用选项不可删除；测试环境只读，报告类型由轮次/周期派生。
6. 参测系统和角色导入在校验成功时原子写入，失败时零写入并返回逐行错误。
7. 后端测试、前端构建、Flyway 与治理检查、真实浏览器桌面/移动验收均记录实际结果。
8. 公告板使用现有全局项目选择器，不重复渲染项目下拉；当前公告、公告管理、附件下载与权限拒绝在四个测试大类下均可验证。
9. 公告管理列表支持标题关键字、发布人、发布时间范围过滤和每页 20 条分页；新建、编辑、查看、置顶/取消置顶、删除均服务端持久化并在当前公告 TAB 同步生效。
10. 测试方案按大类和项目隔离；树中仅显示参测系统，专项节点可维护；同节点同名上传自动递增版本，当前方案与历史版本可通过统一附件能力预览/下载，删除整个方案后保留可恢复数据而不删除单个历史版本。
11. 测试范围仅显示当前大类、项目下启用的参测系统；范围树和案例树彼此独立且均限制五层目录。范围序号为当前大类和项目内唯一键，变更时原子同步关联案例编号前缀，不改变缺陷编号；范围状态按案例执行聚合实时计算，当前无执行记录时为未执行。
12. 测试范围支持目录 CRUD、范围 CRUD、置无效/撤销、软删除、筛选、分页排序、用户级列设置、XLSX 预校验原子导入和按当前节点/筛选条件导出；导入目录最多五层，任一错误行不得写入。
13. 测试案例仅可关联已存在且可见的测试范围；案例编号按“范围序号-流水号”自动生成且不复用，变更所属范围时原子同步编号前缀。案例支持富文本前置条件/操作步骤/预期结果、持久附件、独立核算核对、目录移动、软删除或执行引用下的置无效。
14. 测试案例支持筛选、分页排序、用户级列设置、单条/批量调整、XLSX 预校验原子导入与导出；导入不允许自动创建范围，富文本字段按纯文本导入，所有写操作执行服务端权限、实体范围校验和审计。
15. 测试执行提供系统→轮次→周期→目录树、三种案例预览导入、列表全量筛选、批量成功/失败/提缺陷/移动/移除、富文本结果与备注、独立附件、失败关联保护、实时案例引用、案例状态回算与完整执行轨迹。
16. 测试缺陷提供默认排除已解决的列表、快捷筛选、新增、XLSX 导出、详情编辑、角色受控状态机、平级执行关联及快照、独立附件、轨迹、删除保护和 30 天恢复；缺陷编号在物理子系统内递增且生成后恒定不变。
17. 测试报告支持项目/参测系统树、轮次或周期类型、三步生成、六类章节快照、每章节富文本补充、同对象 V1/V2 历史、Word/PDF 下载、重新生成和不可恢复删除；查看、下载对全体报告阅读角色开放，生成、重生成和删除受服务端权限保护。
18. 分析统计支持四个预置报表、个人与共享自定义报表、可配置维度/指标/图表、筛选与明细钻取、XLSX/图片导出、轮次统计快照、跨轮次对比和带筛选上下文的报告生成入口；首期按项目与测试大类隔离，系统口径仅统计参测系统。
