# 主题模式扇形切换

## 业务目标

平台用户需要在任意工作页面快速切换浅色、深色或跟随系统模式。颜色模式应与配色方案和布局设置解耦，并通过明确的视觉反馈完成切换。

## 范围

### 本次实施

- 在顶部布局和侧栏布局的头部增加独立模式图标。
- 使用太阳、月亮、显示器图标分别表示浅色、深色、跟随系统。
- 点击图标后从图标位置展开三个模式选项，点击外部或 `Escape` 收起。
- 选择模式后，从当前图标位置向页面扩散颜色；系统减少动态效果时直接切换。
- 从主题与布局抽屉移除重复的显示模式选择，保留配色、菜单布局、页签和密度。

### 本次不实施

- 不改变配色方案、布局模式、页签、密度的数据结构。
- 不新增后端接口、数据库字段、权限或外部依赖。
- 不改变既有主题持久化键和登录行为。

## 现状与规则

- `useThemeStore` 已维护 `light | dark | system`，并写入 `ccb.ui-preferences`。
- `AppLayout` 在顶部布局和内容头部各有一套头部操作区，需要保持行为一致。
- 主题颜色通过 `document.documentElement` 的 `data-theme` 和语义 CSS 变量生效。
- 组件必须使用现有 Element Plus 图标，按钮需有 tooltip、`title` 和 `aria-label`。

## 验收标准

1. 当前模式图标正确显示太阳、月亮或显示器；切换后图标、`data-theme` 和持久化值一致。
2. 点击模式图标后，三个选项以图标为中心扇形展开；选择、点击外部、按 `Escape` 均有确定结果，选项不遮挡用户信息。
3. 选择模式时扩散层的圆心取模式图标中心，覆盖整个页面后消失；`prefers-reduced-motion: reduce` 时不播放扩散动画。
4. 主题与布局抽屉不再展示重复的显示模式控件，其他设置仍可用。
5. `npm --prefix web run build` 通过，桌面和移动视口无横向溢出、控制台无新增错误。

## 测试与回退

- 执行前端类型检查和生产构建。
- 使用真实浏览器验证侧栏布局、顶部布局、移动视口、三种模式、外部关闭和刷新持久化。
- 回退方式为恢复本任务新增组件、布局接入、抽屉和样式变更；不涉及数据补偿。
