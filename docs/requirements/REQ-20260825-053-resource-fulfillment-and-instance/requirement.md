# 资源下发与环境部署实例

## 业务目标

将资源工单的实际办理结果逐台落成环境部署实例和实际资源分配，并支持自动部署接口对接（提供 Mock 实现）、手动逐台登记、申请值与实际值差异展示及原因记录、实例采用的部署单元版本差异对比、同部署单元实例间灾备关系管理、实例下线与风险提示、以及基于未下线实例的实际态资源总量汇总。

本需求把 Wayfinder 04 票据转换为仓库正式实施批次。外部 `temp/spec.md`、`temp/CONTEXT.md` 与 `temp/implementation/issues/04-resource-fulfillment-and-environment-instance.md` 作为需求来源和术语证据；用户下达“实现 04 资源下发与环境部署实例，留出对接真实自动部署的接口，目前先mock；实现手动输入和自动部署，自动部署带出资源信息（目前mock）”作为本批次开工授权。

## 范围

### 本次实施

- 自动部署接口与 Mock 提供器：定义可扩展的 `AutomatedDeploymentProvider` 接口，提供默认 `MockAutomatedDeploymentProvider`，支持根据工单信息生成自动部署预览（机器名、IP、资源配额、技术栈、执行日志）。
- 资源下发办理（手动逐台登记 / 自动部署带出）：支持在已审批资源工单上执行下发办理；支持自动部署带出与手动输入模式；逐台登记机器名、IP、实际 CPU/内存/数据库存储/文件存储/CBS/本地盘、网络分区、服务器类型、部署平台和技术栈；展示申请值与实际值差异并强制要求记录差异原因；确认下发时按申请值与实际值是否一致将工单流转为已下发或已差异下发。
- 环境部署实例模型与生命周期：建立环境部署实例主记录；实例与部署单元严格 1:1 归属；同一具体环境中同一机器名与 IP 只能形成一个在用实例；实例采用的部署单元版本独立保存，支持与部署单元最新发布版本对比并展示设计差异；实例业务状态支持在用（`ACTIVE`）与已下线（`OFFLINE`）。
- 灾备关系管理：支持在同一部署单元的在用环境部署实例之间建立主备、双活、冷备等灾备拓扑关系，允许关系跨具体环境（如生产环境主实例与灾备环境备实例）；非同一部署单元禁止建立灾备关系。
- 实例下线与风险控制：支持在用实例下线，记录下线原因、下线人与时间；下线保留完整历史；实例下线时若存在关联灾备关系进行关联风险提示；已下线实例不再计入环境实际资源总量。
- 实际态资源总量动态聚合：环境的实际态 CPU、内存、存储和实际节点数完全由该环境下全部未下线（`ACTIVE`）环境部署实例聚合计算，不允许人工直接维护实际节点数。
- 权限与菜单：新增“环境部署实例”菜单与路由，配置查看/管理权限并授予环境资源办理角色与管理员。
- 追溯与审计：实例与实际资源分配均可追溯至来源工单；写操作执行操作审计。

### 本次不实施

- 搭建计划、环节、任务、检查项流程（属于 05 及后续搭建任务批次）。
- 交付单元、代码仓库、流水线与交付制品版本映射（属于交付与制品批次）。
- 网络访问关系实际开通与网络分区策略引擎（属于网络访问批次）。

## 业务规则

1. 环境部署实例是部署单元在具体环境中落到单台机器及其 IP 的最小实际部署对象；一个实例只归属一个部署单元。
2. 同一具体环境中同一机器和 IP 只能形成一个在用（`ACTIVE`）实例；机器用途或 IP 变化通过下线旧实例、基于新部署单元或新 IP 创建新实例保留两段历史，不得直接覆盖原实例。
3. 普通用户不能手工直接新建实例；日常新增实例必须通过资源申请工单办理下发产生。
4. 资源办理支持“自动部署”与“手动输入”两种模式；自动部署调用 `AutomatedDeploymentProvider` 接口获取下发结果并可微调后确认；Mock 自动部署随机生成私网 IP，同一环境/部署单元下带出的主机名按已有实例数量延续自增；系统展示申请值与实际值的差异，当实际值与申请值存在差异时必须填写差异原因。确认下发后，实际汇总值与申请汇总值一致的工单状态为“已下发”，不一致的工单状态为“已差异下发”。
5. 实例创建时记录采用的部署单元版本（`deploymentUnitVersionNo`），当部署单元主记录发布新版本时，实例版本不会自动升级，页面显式展示版本差异。
6. 同一部署单元的实例之间支持建立主备（`PRIMARY_STANDBY`）、双活（`ACTIVE_ACTIVE`）、冷备（`COLD_STANDBY`）灾备关系，允许跨具体环境；不同部署单元之间不允许建立灾备关系。
7. 实例下线记录操作人、下线时间和下线原因；下线不物理删除记录；若实例存在灾备关系，提示关联风险。
8. 具体环境的实际态资源总量（实际 CPU、实际内存、实际存储、实际节点数）按该环境所有 `ACTIVE` 实例动态汇总计算，已下线实例不计入当前总量。

## 验收标准

1. 资源工单在审批通过后，办理人员可选择“自动部署带出”或“手动输入”执行资源下发；自动部署能带出自增主机名、随机私网 IP 和规格信息，确认后落成环境部署实例及实际资源分配。
2. 实际下发值与申请值存在差异时，系统正确展示差异并校验差异原因必填；确认下发后，一致工单显示为“已下发”，不一致工单显示为“已差异下发”；工单和实例均可追溯来源与变更历史。
3. 同一环境同一机器/IP 不允许存在多个在用实例；普通用户不可手工直接新建实例；实例与部署单元严格 1:1。
4. 实例详情可查看当前采用的部署单元版本，当部署单元有新版本时展示版本差异标签。
5. 同一部署单元实例之间可成功创建和解除灾备关系（支持跨环境），不同部署单元被拒绝。
6. 实例可正常下线并保留历史记录；下线实例退出环境实际资源汇总；若存在灾备关系显示风险提示。
7. 具体环境资源汇总中的实际态 CPU、内存、存储和节点数准确反映当前未下线实例的汇总值。
8. 单元测试、Flyway 迁移检查、前端构建与检查均通过。
