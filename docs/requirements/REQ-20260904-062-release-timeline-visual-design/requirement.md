# 投产方案时序图视觉重构

## 业务目标

参考用户提供的脱敏视觉图片，将投产方案中的正向投产时序和回退时序从普通横向指令卡片改为可扫描的阶段列时序图。图片只作为视觉参考，不增加图片中的业务字段或额外业务规则。

## 必须实施

- 正向和回退时序抽屉均使用阶段列布局：按指令序号归并为阶段列，列内展示该阶段的指令内容。
- 阶段列展示 `P` 编号、阶段标题、指令数量和时间范围；指令保留名称、时间、负责人、状态、说明及编辑/删除入口。
- 阶段列底部增加贯穿全部阶段的横向时间轴、阶段节点和时间标签，时间标签与对应阶段保持一致。
- 同一时序中的多条指令按序号、开始时间稳定排序；相同序号归并到同一阶段列。
- 无指令时继续展示空状态；无权限时继续保持只读，不出现写操作入口。
- 桌面端完整呈现图形，小屏只允许时序图内部横向滚动，页面不产生级联横向溢出。

## 不实施

- 不新增或修改后端接口、数据库字段、迁移或权限规则。
- 不新增独立阶段实体，不把图片中的阶段名称、检查点或品牌内容写入业务数据。
- 不改变时序名称、指令新增/编辑/删除、时间范围、负责人、状态和乐观锁行为。

## 验收标准

1. 正向和回退时序抽屉都呈现阶段列、列内指令和底部贯穿时间轴。
2. 多条指令按序号归并、按开始时间排列，序号与时间标签可读且不遮挡内容。
3. 现有自定义时序名称及指令维护入口继续可用，保存数据后图形即时更新。
4. 空数据、只读权限、长指令名称和 `375/390/430/1280` 视口均无页面级横向溢出。
5. 前端构建、差异检查及浏览器验收无新增错误。

## 回退

仅回退本任务新增的 `ReleaseDrillPlanView.vue`、`release-operations.css` 和对应任务证据文件；不影响上一轮后端及数据库变更。
