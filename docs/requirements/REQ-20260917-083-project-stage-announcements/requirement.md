# 项目阶段公告栏

## 业务目标

项目成员在项目详情中按实施阶段维护和查看公告。项目概览只展示当前日期命中的实施阶段公告，使项目成员进入项目后能够直接获取当前阶段的置顶通知和最新信息。

## 范围

### 本次实施

- 项目详情新增“公告管理”页签，项目成员均可按项目阶段新增、编辑、置顶和删除本项目公告。
- 项目概览在项目信息区域右侧增加公告栏；桌面端横向布局，移动端移至项目信息下方。
- 公告包含项目阶段、标题、富文本正文和置顶标记；概览显示正文摘要。
- 当前阶段由当天命中的顶级项目计划阶段确定；并行命中多个阶段时展示全部阶段公告。
- 新增项目自有公告表、项目服务 CRUD 接口、成员实体授权、乐观锁与操作审计。
- 修复项目详情上下文隔离：详情路由中的项目是该页面所有项目资源请求的唯一目标，顶部项目选择器不因进入详情而切换；项目详情请求携带与路径一致的项目上下文。

### 本次不实施

- 不复用测试管理公告、站内消息或配置管理投产窗口数据。
- 不发送提醒、站内消息、邮件或短信，不做跨项目汇总、附件、审批、定时发布或历史归档页面。
- 不修改项目计划、项目阶段、项目角色及已有项目页签的业务规则。

## 现状与规则

- 当前入口为 `ProjectView.vue`，详情页签状态由 `?tab=` 维护；项目阶段由 `pm_project_stage` 维护，顶级项目计划保存阶段和计划日期。
- 公告归项目模块所有，按 `tenant_id` 与 `project_id` 隔离。只有已登录项目成员可读取和维护本项目公告；成员可修改或删除任意本项目公告。
- 当前阶段为今天落在顶级项目计划的计划开始与结束日期（含边界）内的阶段集合；无匹配时概览显示明确空状态，不展示其他阶段公告。
- 同一公告的置顶仅影响其所属阶段内排序；概览按置顶、阶段顺序、发布时间倒序排列。
- 创建、更新、置顶和删除均保留操作审计；删除采用逻辑删除，更新与删除执行乐观锁校验。

## 接口与数据

- 新增项目公告列表、创建、更新、删除接口，以及项目概览的当前阶段公告查询。
- 新增 `pm_project_announcement` 表，字段包含主键、租户、项目、阶段编码、标题、富文本正文、置顶标记、创建/更新审计、逻辑删除和版本号。
- 富文本输出必须经受控渲染或净化，禁止脚本与危险 URL；服务端校验阶段属于当前项目且项目成员关系、租户和实体归属均有效。
- 迁移仅追加 `V215__project_stage_announcements.sql`；回退应用代码时保留公告数据作为只读证据。

## 验收标准

1. 项目详情可通过 `tab=announcements` 打开公告管理，现有页签及路由行为保持不变。
2. 项目成员可按阶段创建、编辑、置顶和删除公告；刷新后内容、阶段和置顶状态持久化回显。
3. 非项目成员、跨租户请求和阶段不属于项目的请求均在服务端被拒绝；旧版本更新或删除被拒绝且前端提示刷新。
4. 项目概览仅展示当前日期命中的顶级项目计划阶段公告；并行阶段均展示，置顶公告优先。
5. 无当前阶段或当前阶段无公告时，概览显示明确空状态；桌面和 375x812、390x844、430x932 视口均无页面级横向溢出。
6. 富文本公告不能执行脚本或渲染危险链接，删除和写操作均保留审计。
7. 顶部当前项目与已打开的项目详情不同时，项目基础信息、设置、计划、风险、成员、组织、角色、公告、投产日历和附件仍可读取及维护详情项目；顶部选择器值不因进入详情或保存详情而改变。

## 测试与发布

- 必须执行：项目服务聚焦测试、迁移集成测试、公告 API 与成员/跨租户/乐观锁测试、前端构建、治理与范围检查、桌面及规定移动视口浏览器验收。
- 上线验证：以项目成员身份维护不同阶段公告并验证概览筛选与置顶排序；以非成员身份验证拒绝访问。
- 回退：回退本需求的应用代码和前端页签；不回滚已发布 Flyway 迁移，不删除已写入公告数据。
- 风险与人工复核人：平台系统 Owner 复核富文本安全、成员授权、审计与迁移；项目 Owner 复核阶段判定和概览展示。
