# Project Overview Dashboard

## Goal

优化项目概览的信息层级，在项目详情、项目说明和项目日历之外，提供计划维度的可扫描统计看板。

## Scope

- 项目概览顶部展示项目名称、状态、负责人、日期范围和整体计划进度。
- 增加计划总数、已完成、进行中、未开始、已阻塞和平均进度 KPI。
- 增加计划状态分布、计划进度排行和计划排期统计图。
- 保留项目说明与项目日历，并在桌面端合理分栏、移动端单列适配。
- 图表直接派生自项目详情返回的 `plans`，不新增接口、数据库字段或独立日历数据。

## Invariants

- 项目可见性、权限和计划数据范围继续由现有后端接口控制。
- 现有项目管理单菜单、中文界面、主题变量和计划树结构保持不变。
- 空计划、无日期计划、长名称和窗口尺寸变化均有可预期表现。

## Acceptance

1. 项目概览可以同时查看项目详情、计划 KPI、三类计划统计图、项目说明和项目日历。
2. 统计图数据随项目详情刷新更新；切换深浅主题后使用当前主题颜色。
3. 图表支持窗口 resize，并在页面卸载时销毁实例；无计划时显示空状态。
4. 桌面、窄屏和移动布局不产生横向溢出或内容遮挡。
