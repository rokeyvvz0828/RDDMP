# 修复数据表固定列背景透出

## 业务目标

平台用户横向滚动数据表时，固定在左侧或右侧的列必须保持不透明，不能透出其下方滚动经过的文字和控件。

## 范围

### 本次实施

- 修复公共 `UiDataTable` 中 Element Plus 左、右固定列的数据单元格背景。
- 保留表头、行悬停、斑马纹、当前行和明暗主题的既有语义颜色。
- 回归至少一个右固定列和一个左固定列的数据表。

### 本次不实施

- 不修改具体业务页面、表格字段或操作逻辑。
- 不修改后端接口、权限、审计、数据库或外部系统。
- 不调整移动端列表与卡片的呈现规则。

## 现状与规则

- `web/src/styles.css` 将普通表格行背景设为透明。
- Element Plus 2.14 使用 `el-table-fixed-column--left` 和 `el-table-fixed-column--right` 的粘性单元格实现固定列，固定单元格继承透明行背景后会透出滚动内容。
- 修复必须使用现有 `--panel-bg`、`--panel-muted` 等语义主题变量，并保留 Element Plus 的悬停和状态样式优先级。

## 接口与数据

- API/事件契约：无变更。
- 数据 Owner：无变更。
- 数据库迁移与存量兼容：不适用。
- 敏感信息：不涉及。

## 验收标准

1. 横向滚动时，左、右固定列的数据单元格均不透出其下方内容。
2. 固定列与普通列在行悬停时使用一致的悬停背景。
3. 固定列表头和滚动条补丁在浅色、深色主题下使用语义背景色。
4. 不带固定列的 `UiDataTable` 外观不变。
5. `npm --prefix web run build`、治理检查和 `git diff --check` 通过。

## 测试与发布

- 构建：`npm --prefix web run build`。
- 浏览器：桌面视口检查左右固定列横向滚动、行悬停、浅色和深色主题。
- 上线验证：打开任一带固定操作列的数据表并横向滚动。
- 回退：回退本需求对 `web/src/styles.css` 的固定列样式规则。
- 风险与人工复核人：公共表格样式可能影响多个页面，由前端 Owner `rokeyvvz0828` 复核。
