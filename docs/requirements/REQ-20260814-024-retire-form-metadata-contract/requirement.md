# 下线输入项配置强制契约

## 目标

将已经下线的“输入项配置/业务表单元数据”能力从项目强制开发契约中移除，避免后续业务模块和 Agent 继续新增依赖。

## 规则

- 新业务默认由所属模块维护独立的前端页面、字段 DTO、校验规则、数据库结构和 Mock 数据。
- 新业务不得依赖 `biz_form_*` 表、输入项配置管理接口或新增已发布表单查询契约。
- 现有输入项配置代码、迁移和历史数据暂时保留，不在本需求中删除。
- 未来需要重新启用时，必须通过单独的 `ready` 需求重新确认范围、权限、公开契约、数据迁移和验收标准。

## 验收标准

1. 根 `AGENTS.md` 和开发指引不再要求业务任务维护表单元数据。
2. 表单元数据契约明确标记为已下线和仅供存量兼容参考。
3. Mock 契约不再要求新业务登记 `biz_form_*` 数据。
4. 不删除输入项配置的现有产品代码和数据库历史迁移。

## 回退

恢复本需求修改的四份契约文档；不涉及数据补偿。
