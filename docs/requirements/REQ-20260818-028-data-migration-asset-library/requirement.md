# 数据迁移项目资产库核心业务

## 业务目标

在数据迁移业务中提供以正式项目为数据范围的非结构化资产库，使项目成员能够按权限管理目录、文件元数据、审核、标签、备注、收藏、受控外链和永久回收站，同时复用项目、附件、工作流和审计平台能力。

## 范围

### 本次实施

- 建立独立 `ccb-data-migration` 业务模块并登记公开 API、依赖和所有权。
- 文件编号由系统生成 UUID；保存项目、附件、目录、展示文件名、文件大小、类型、上传时间、上传用户、MD5 和 SHA-256。
- 提供目录树、新建/改名/移动/删除目录和文件拖拽换目录所需接口。
- 提供按项目、文件编号、文件名、目录、标签、审核状态、上传用户和时间范围的服务端分页查询。
- 文件内容不可覆盖；更新接口仅允许修改名称、目录、标签和备注。
- 提供单个/批量进入回收站、恢复和有权限的彻底删除；回收站永久保留，不自动清理。
- 提供项目级标签库、单个/批量标签关联、追加式备注、备注撤回和单个/批量收藏。
- 提供显式提交审核、撤回和审核历史，复用平台工作流；审核中冻结元数据。
- 提供强约束外链：高熵令牌、必填提取码、最长 7 天、访问次数、预览/下载分权、撤销、限流和审计。

### 本次不实施

- 不实现普通/迁移包导入导出和最终统一前端页面，这些属于 `REQ-20260818-029`。
- 不实现全文检索、OCR、在线编辑、文件二进制覆盖、文件版本或跨项目存储去重。
- 不复制项目表、附件对象键、工作流表或平台审计实现。

## 现状与规则

- 依赖 `REQ-20260818-026` 的正式项目上下文和 `REQ-20260818-027` 的持久附件能力。
- 有效权限为平台 RBAC、项目角色范围和资产状态允许操作的交集。
- 项目成员可查看草稿、审核中、已通过和驳回状态；状态必须明确展示，审核中的元数据不可修改。
- 项目归档后资产只读并撤销全部外链；文件进入回收站时外链立即失效。
- 内容变化必须创建新的 UUID 文件；同项目摘要重复时提示已有文件，用户确认后仍可创建独立资产。
- 标签属于项目级受控标签库；备注为追加式记录，批量备注为每个文件追加同一内容。

## 接口与数据

- API 包括目录、资产查询/详情/元数据、批量移动、回收站、标签、备注、收藏、审核和分享。
- 核心数据包括资产、目录、标签及关联、备注、收藏、分享、分享访问日志和工作流绑定。
- 资产同时维护附件可用状态、审核状态和生命周期状态；附件扫描状态来自附件公开契约，不由业务模块伪造。
- 外链数据库只保存令牌摘要和 BCrypt 提取码哈希；访问次数使用原子更新。
- 所有业务写操作记录操作人、对象、动作、结果和 trace ID；外部访问按最小化原则记录来源摘要。

## 验收标准

1. 系统自动生成 UUID 文件编号，并从已扫描附件和认证主体写入文件名、大小、类型、摘要、上传人和时间。
2. 查询条件、服务端分页、目录懒加载和同级目录唯一约束正确，循环移动和非空目录删除被拒绝。
3. 文件内容不能通过更新接口替换；审核中元数据冻结，并发更新产生明确冲突。
4. 项目成员能按角色和平台权限执行查看、上传、更新、下载、预览、分享、收藏、标签、备注和审核操作。
5. 外链满足提取码、7 天上限、访问次数、预览/下载分权、撤销、限流和失效规则。
6. 删除进入永久回收站；恢复保持业务关联；彻底删除清理对象及业务关联但保留不可变审计。
7. 跨租户、跨项目、非成员、只读越权、状态越权和 UUID 猜测不泄露资产存在性。
8. 10 万文件项目首屏查询 `p95 <= 800ms`，目录子节点查询 `p95 <= 300ms`。

## 测试与发布

- 必须执行数据迁移模块单元/集成测试、项目/附件/工作流契约测试、API/权限/并发/外链安全测试、全量 Maven、治理和任务范围检查。
- 上线验证项目归档、上传扫描结果绑定、审核流、外链失效、回收恢复及彻底删除审计。
- 回退应用时关闭资产入口、外链和后台任务，保留资产、审核、分享、审计和对象数据，不执行生产 `DROP`。
- 风险包括跨模块契约、项目级数据范围、匿名外链、永久回收站、对象一致性和工作流事件；需相关 Owner 专项复核。
