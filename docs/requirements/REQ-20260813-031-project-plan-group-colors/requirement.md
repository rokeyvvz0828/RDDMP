# 项目计划分组配色

## 目标

项目计划分组支持从系统主题配色中选择颜色，并在计划表中以稳定、可读的同色系视觉标识区分分组。

## 范围

- 新建和编辑计划分组时可以选择系统已有主题配色。
- 分组颜色持久化到项目计划分组记录，刷新项目或重新登录后保持不变。
- 历史分组颜色为空时使用 ocean 作为兼容默认值。
- 计划表分组行使用选定主题的浅色背景和左侧色条；分组下主计划、子计划显示同色系边界标识。
- 后端只接受已登记的主题配色编码，继续复用现有计划权限、项目实体授权、租户隔离和审计。

## 非目标

- 不新增独立主题，不修改系统主题设置页面。
- 不改变计划分组层级、拖放规则、计划编号规则和权限编码。
- 不修改已发布 Flyway 迁移，只追加 V41。

## 验收条件

1. 新建分组选择配色后保存，刷新项目仍显示同一颜色。
2. 编辑分组可以更换配色，分组行及其计划行立即使用新颜色。
3. 旧分组或空颜色数据显示 ocean，不出现空白或未定义样式。
4. 非法颜色编码由服务端拒绝，并且不绕过现有权限和租户校验。
5. 前端类型检查、Flyway 检查、治理检查和 `git diff --check` 通过；受环境限制的检查如实记录。
