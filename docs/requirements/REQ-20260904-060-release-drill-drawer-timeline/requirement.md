# 投产演练时序与抽屉交互优化

## 业务目标

让投产方案和演练轮次的步骤信息以时序图方式快速理解，并通过抽屉完成维护；投产管理页面不重复展示当前项目标识，项目上下文统一由顶部项目切换栏提供。

## 必须实施

- 投产演练计划的每个投产方案展示正向投产和回退两个横向时序图，步骤按序号连接，节点显示名称、时间、负责人和状态。
- 正向/回退时序的新增和编辑均从对应时序图打开抽屉；删除仍使用确认弹框，保存后回到时序图并刷新数据。
- 投产演练当前轮次的步骤使用抽屉新增和编辑；步骤抽屉保留负责人、时间范围、状态、结果和说明字段，列表改为时序化展示。
- 移除投产管理页面标题右侧的“当前项目”信息块，不影响顶部项目切换和当前项目数据加载。

## 不实施

- 不改后端接口、数据库结构、权限、项目切换逻辑和投产数据模型。
- 不恢复或新增投产时序独立菜单。
- 不改变方案、轮次、步骤的业务校验、删除确认和乐观锁行为。

## 验收标准

1. 方案详情同时展示正向和回退横向时序图，步骤顺序、时间、负责人和状态可识别。
2. 点击正向/回退时序图的新增或编辑操作，出现抽屉；保存成功后抽屉关闭且对应时序图更新。
3. 当前轮次点击新增或编辑步骤，出现抽屉；保存成功后步骤时序区更新，删除确认仍可用。
4. 投产管理五个页面不再显示“当前项目”信息块，顶部项目切换后的数据加载不受影响。
5. 前端生产构建通过，投产相关后端回归测试通过，桌面页面无新增横向溢出和控制台错误。

## 回退

仅回退本任务前端文件和任务文档，不涉及数据库迁移；保留既有后端接口和数据。
