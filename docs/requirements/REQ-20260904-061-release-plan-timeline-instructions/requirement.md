# 投产方案时序指令与抽屉交互

## 业务目标

在投产演练计划中按投产方案维护正向和回退时序。时序在抽屉中查看和维护，名称可自定义，每条时序支持多个指令；投产演练环境的新增和编辑也统一使用抽屉。

## 必须实施

- 投产方案详情的正向投产时序和回退时序使用抽屉展示。
- 正向和回退时序名称可分别自定义并持久化到当前投产方案。
- 每条时序支持新增、编辑、删除多个指令，保留序号、时间范围、负责人、状态、说明和乐观锁行为。
- 方案时序入口和表单统一使用“指令”文案，不再使用“步骤”。
- 投产管理页面移除顶部“投产管理”字体及描述。
- 投产演练环境新增和编辑使用抽屉。

## 不实施

- 不恢复投产时序和投产回退时序独立菜单。
- 不改变项目切换、权限校验、演练轮次和演练步骤接口。
- 不依赖 biz_form_* 元数据能力。

## 数据与权限

- 为 `rel_release_plan` 追加正向、回退时序名称字段，历史记录使用默认名称回填。
- 复用现有投产方案和方案指令服务端认证、项目成员校验、权限和 rowVersion 校验。
- 迁移只追加，不修改已发布迁移；不连接生产系统。

## 验收标准

1. 方案详情可分别打开正向和回退时序抽屉，抽屉中显示自定义名称和指令时序。
2. 可在每条时序中新增多个指令，并可编辑、删除，保存后列表更新。
3. 方案页面所有对应新增、编辑、删除文案使用“指令”。
4. 环境新增和编辑打开抽屉，保存、取消、删除确认和项目数据切换正常。
5. 投产管理页面不渲染顶部“投产管理”标题及描述，前端构建、后端回归、浏览器和差异检查通过。

## 回退

回退本任务新增迁移及对应模型、服务、API、投产前端文件和任务记录；保留上一任务已发布迁移，不手工回退数据库结构。
