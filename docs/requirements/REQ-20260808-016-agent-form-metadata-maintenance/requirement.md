# REQ-20260808-016 Agent 自动维护业务表单元数据

status: ready

## 目标

将业务表单元数据的初始化维护责任明确纳入 Agent 的业务开发契约，避免研发人员在系统设置中重复手工配置大量字段、分区和规则。

## 实施范围

- 更新业务表单元数据公共契约，规定 Agent 随业务代码同步交付初始化配置和 mock 数据。
- 更新 mock 数据契约、仓库 `AGENTS.md` 和 `CODEX-DEVELOPMENT-GUIDE.md`，让后续 Agent 在进入业务任务时能够识别并执行该要求。

## 验收标准

- 明确系统设置页面不是新业务上线的人工前置步骤。
- 明确 Agent 必须维护 scope、section、field、rule、option 及 mock/初始化数据。
- 明确全新本地数据库首次启动无需人工配置即可看到业务表单能力。
- 明确需求记录、任务范围和 `.ai-control` 证据需要记录初始化文件、版本、回退和验证。

## 非目标

- 本需求不实现新的动态表单业务模块。
- 本需求不修改现有业务逻辑和数据库结构。
