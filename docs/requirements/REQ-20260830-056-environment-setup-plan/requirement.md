# 环境搭建计划（测试环境搭建管理）

## 业务目标

把测试环境搭建从“线下文档 + 例会跟踪”转变为平台内的结构化闭环：以“计划模板/任务模板（版本化）→ 搭建计划 → 环节 → 任务 → 检查项”组织搭建工作，提供模板复用、按目标批量生成任务、执行与豁免留痕、前置依赖与阻塞登记、计划/实际时间与逾期、运行中调整、工单关联门禁、进度看板与时间视图，支撑环境搭建的可视化、可追溯和可复用。

本需求把 Wayfinder 05-08 票据转换为仓库正式实施批次。外部 `temp/spec.md`（用户故事 50-94）、`temp/CONTEXT.md`（环境搭建领域词汇）与 `temp/implementation/issues/05-08` 为需求来源和术语证据；用户下达“实现测试环境搭建管理，功能点菜单名为环境搭建计划”，并确认“一个批次全量实施（模板与生成、执行与豁免、依赖/阻塞/时间、调整与跟踪）”和“环境搭建计划 + 搭建计划模板 两个菜单平行”作为本批次开工授权。

## 范围

### 本次实施

- **计划模板与任务模板（版本化）**：模板管理员维护计划模板（含多环节）和任务模板（含标准检查项、任务生成维度：不展开/按物理子系统/按部署单元）；已发布版本不可原地改写，调整形成新版本并保留发布历史；模板可停用，停用不影响既有计划。
- **计划创建与任务生成**：计划责任人只能从已发布计划模板创建计划，选择具体环境与目标（物理子系统/部署单元），系统保存模板版本、执行结构与目标快照，未选目标不进入计划；按任务模板生成维度分别为每个目标生成独立任务与独立检查项；计划/环节/任务责任人与任务参与人支持模板或上级继承与生成后调整，调整留痕。
- **任务执行与检查项**：满足前置条件的任务可开始；检查项支持完成、重新打开、备注与可选附件并保留事件历史；任务、环节、计划完成状态与进度自下而上按当前有效检查项计算，不允许通用状态或人工进度覆盖；有效子项重新打开后上级立即退出已完成并重算。
- **取消豁免与恢复**：计划责任人可附原因取消未完成检查项、任务、环节或计划（任务责任人与参与人只能提交附原因的检查项取消建议）；取消内容保留历史并退出完成条件与进度，恢复后重新纳入并触发重算；全部检查项/任务取消时显示“全部豁免”，全部环节取消时计划不得自动完成；计划取消为独立终态，恢复后继续使用取消前快照。
- **前置依赖**：任务间显式声明前置依赖，支持移除与改绑；前置未完成时后续任务不能开始并显示“等待前置”（不产生阻塞记录）；前置任务被取消不等同完成，后续继续等待并提示“依赖已取消”；建立依赖时校验循环。
- **阻塞记录**：任务可登记多条阻塞记录（描述、影响范围、责任人、预计解决时间），支持解除；存在未解除阻塞时任务计算为阻塞，解除后恢复进度状态；环节与计划聚合显示“存在阻塞”并可下钻；任务取消后阻塞保留但不传播。
- **计划与实际时间、事件更正与逾期**：计划/环节/任务维护计划开始/结束时间，计划开始后调整需附原因并保留前后值；实际开始/完成由开始、完成、重新打开等执行事件聚合，不允许直接编辑；有权限人员可附原因更正事件，原事件与更正记录保留；子项计划时间超出上级提示风险但不阻止；逾期作为独立标识按当前时间/计划结束/取消状态计算并向上聚合，取消后不计算当前逾期，恢复后重算。
- **运行中调整与工单关联**：计划开始后计划责任人可附原因新增环节、任务、检查项与目标（新目标按该计划自身模板快照生成任务）；移出目标时未完成任务自动取消、已完成保留；从未执行的错误内容可附原因删除并记录操作人/时间/原因；任务可发起或事后关联资源申请、网络专项工单（CLB/DNS/证书），存在未结束关联工单时任务不能完成，工单结束只解除门禁不自动完成任务。
- **查询、看板、时间视图与报告**：按具体环境、计划、环节、责任人、目标、状态、阻塞、逾期和豁免查询，从汇总下钻到检查项与操作历史；计划详情提供按环节分组的进度看板、时间视图（甘特）与搭建结果报告；报告可导出 Excel（复用 `xlsx` 库，内容与筛选一致）；所有汇总数字与状态均来自同一计算事实。
- **通知**：复用平台站内通知能力发送任务分派、工单状态变化、阻塞、临期、逾期和关键状态变更通知；通知失败不改变业务事实。
- **权限与菜单**：新增“环境搭建计划”与“搭建计划模板”两个菜单（菜单 814/815）（并列于架构管理菜单树），配套查看/管理权限并授予超管与环境资源办理角色；页面显隐不能替代后端校验。
- **审计与历史**：关键写操作、取消与恢复、事件更正、责任人调整、目标增减、依赖与阻塞变更、工单关联、模板发布记录操作人、时间、原因与前后值。

## 业务规则

1. 计划只能从已发布计划模板创建，不能直接新建空白计划；同一具体环境可先后或同时拥有多个相互独立且目标可重叠的未结束计划，平台不做互斥限制。
2. 生成计划时保存模板版本（计划模板与任务模板版本号）、环节/任务/检查项内容快照与目标快照；模板后续更新或停用、架构资产后续变化只产生差异提示，不自动改写既有计划与任务。
3. 任务生成维度决定按哪类目标分别生成任务：不展开=每个环节的任务模板生成一个任务；按物理子系统=为每个选中的物理子系统生成一个任务；按部署单元=为每个选中的部署单元生成一个任务。同一任务模板生成的多个任务结构相同、互不影响。
4. 任务状态由业务动作与领域规则计算（未开始/等待前置/进行中/阻塞/已完成/已取消），用户只执行开始、重新打开等动作，不能任意改写；逾期是独立标识，不替换执行状态。
5. 完成条件：任务=全部未取消检查项完成；环节=全部未取消任务完成；计划=全部未取消环节完成。有效子项重新打开后上级立即退出已完成并重算。
6. 进度 = 当前有效范围内已完成检查项数 ÷ 全部未取消检查项数（已取消环节与任务下的检查项整体退出计算）；不允许人工填写或加权。任务检查项全部取消时进度 100% 并标记“全部豁免”；环节任务全部取消时显示“已完成（全部豁免）”；全部环节取消的计划不得自动完成。
7. 检查项取消：计划责任人可直接取消/恢复；任务责任人与参与人只能提交附原因的取消建议，由计划责任人处理，不另设审批流。
8. 前置依赖：前置任务完成前后续任务不能开始并显示等待前置，不产生阻塞记录；前置被取消不等同完成，后续继续等待并提示依赖已取消，直到计划责任人移除、改绑依赖或取消后续任务；依赖建立时校验循环。
9. 阻塞记录独立于依赖：存在未解除阻塞记录时任务计算为阻塞，解除后按实际进度状态恢复；环节与计划聚合“存在阻塞”。
10. 实际开始/完成时间由执行事件产生：计划与环节的实际开始取首个有效子项实际开始，实际完成取最近一次完成事件；重新打开并再次完成后当前实际完成时间取最近完成；事件更正由有权限人员附原因执行，原事件与更正记录全部保留。
11. 逾期：当前时间超过计划结束时间且对象未完成时产生；任务取消/环节取消/计划取消后不计算当前逾期且不向上聚合（取消前逾期保留历史），恢复后按当前时间与计划结束时间重判；计划时间调整后按新时间重算当前逾期并保留曾经逾期历史。
12. 子项计划时间超出上级计划时间范围时提示风险但不阻止保存；计划时间调整必须附原因并保留前后值。
13. 移出目标：关联未完成任务自动取消（记录原因），已完成记录保留；新增目标按该计划自身模板快照生成任务。
14. 删除限制：已经开始或完成的内容不得物理删除；从未执行的错误内容可附原因删除并记录操作人、时间与原因。
15. 工单关联门禁：任务存在未结束关联工单（资源申请：状态非已办结终态；网络专项工单：状态非已完成/已取消终态）时不能完成；工单结束只解除约束，不自动完成任务。
16. 计划取消为终止整个未完成计划的业务动作，必须填原因；取消后停止新增和执行任务，所有历史保留；“已取消”与“已完成”是不同终态。
17. 计划、环节、任务责任人：计划责任人负责整体协调与全部豁免/取消/恢复/依赖/目标调整；环节责任人负责阶段推进（环节内任务与检查项操作）；任务责任人负责本任务执行；任务参与人可操作任务检查项（完成/重开/备注/附件）但不能取消检查项。
18. 通知：任务分派、工单状态变化、阻塞、临期、逾期、关键状态变更调用平台站内通知；通知失败不影响业务状态与完成条件。

## 验收标准

1. 模板管理员可维护计划模板（多环节）与任务模板（检查项、生成维度），发布新版本后旧版本内容不可改变且可查看版本历史；停用模板后既有计划不受影响。
2. 计划责任人从已发布模板创建计划：选择环境与目标后，系统按模板与生成维度生成环节、任务与独立检查项；未选目标不进入计划；计划/环节/任务责任人与参与人可继承并可调整且留痕。
3. 任务满足前置后可开始；检查项完成/重新打开/备注/附件均记录操作人与时间；任务、环节、计划状态与进度由系统计算且不可覆盖；重新打开有效子项后上级立即退出已完成并重算。
4. 计划责任人可附原因取消/恢复检查项、任务、环节与计划；任务责任人与参与人只能提交检查项取消建议；所有取消/恢复内容保留历史；全部取消时显示“全部豁免”，全部环节取消的计划不自动完成。
5. 前置依赖：未满足时任务不能开始并显示等待前置；前置取消后后续任务提示依赖已取消；支持移除/改绑；循环依赖被拒绝。
6. 阻塞登记/解除后任务状态正确变化并在环节、计划层聚合显示；可下钻查看具体阻塞记录。
7. 计划/环节/任务计划时间可维护并在开始后附原因调整；实际时间由事件聚合；附原因事件更正后重算且原记录保留；逾期标识按规则计算与聚合。
8. 计划开始后可新增环节/任务/检查项/目标；移出目标后未完成任务自动取消、已完成保留；未执行错误内容可附原因删除。
9. 任务关联资源/网络工单后，存在未结束工单时无法完成任务；工单结束只解除门禁；关联与解除留痕。
10. 计划详情看板、时间视图、报告数据与列表查询来自同一计算事实；Excel 导出内容与筛选一致；查询支持环境、责任人、目标、状态、阻塞、逾期、豁免维度并可从汇总下钻到检查项与操作历史。
11. 通知在任务分派、工单状态变化、阻塞、临期、逾期与关键状态变更时发出；通知失败不影响业务事实。
12. 权限：无权限用户页面不可见、接口 403；非任务责任人与参与人不能操作任务检查项；非对应层级责任人不能取消/恢复/调整依赖与时间。
13. 单元测试、公开 API 场景、真实 MySQL/Flyway、前端构建与治理检查通过；桌面与移动视口（375x812/390x844/430x932/1280x800+）完成真实浏览器验收。
