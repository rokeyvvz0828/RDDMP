# 交付示范中心前端样式参考模块

## 业务目标

在当前基础框架中提供一个可直接操作的虚构交付业务模块，集中沉淀后续需求、研发、测试、版本、数据迁移和投产类页面可复用的交互与视觉参考，避免业务研发各自设计列表、表单、详情、审批和可视化页面。

## 范围

### 本次实施

- 以交付项目、里程碑、风险和审批为统一业务对象，提供工作台、项目列表、图表分析、计划甘特和流程审批视图。
- 保留原“组件示例”菜单和 `/components` 页面，新增“交付示范中心”一级菜单及独立 `/delivery-showcase` 路由。
- 提供列表检索、组合筛选、分页、排序、批量操作、标准新建表单、分步新建表单、弹框表单、抽屉详情、标准详情和分步只读详情。
- 提供柱状图、饼图、折线图、甘特图、流程图、审批动作、确认提示、结果提示、附件、时间线、空数据、加载失败和无权限示例。
- 使用本地虚构 mock 数据，交互结果在当前页面会话内生效。
- 支持现有语义主题、明暗模式及桌面和移动视口。

### 本次不实施

- 不新增后端接口、数据表或服务端业务逻辑；仅追加一级菜单配置迁移。
- 不将 mock 数据持久化，不实现真实上传、导入、导出、消息通知或流程引擎调用。
- 不把前端权限演示作为服务端鉴权实现。

## 现状与规则

- 原入口 `/components` 继续展示公共组件示例，不改变原页面逻辑。
- 新模块使用独立 `/delivery-showcase` 入口，并通过动态菜单配置为一级菜单。
- 页面复用现有公共 UI 组件、Element Plus、Vue Flow 和主题变量；图表使用 ECharts。
- 所有姓名、项目、编号和统计数据均为虚构测试数据，不包含生产信息。

## 接口与数据

- API/事件契约：无后端 API 变化，模块只使用本地 TypeScript mock 数据。
- 数据 Owner：本示范模块页面状态。
- 数据库迁移与存量兼容：追加 `V25__seed_delivery_showcase_menu.sql`；不修改原菜单 `ID=400`，新增 `ID=500` 并授权超级管理员角色。
- 脱敏输入输出示例：`DLV-2026-014 / 统一支付能力升级 / 林川` 均为虚构内容。

## 验收标准

1. 用户可检索、筛选、排序、分页和批量处理交付项目，并区分正常、无结果、失败、加载和无权限状态。
2. 用户可分别完成标准表单、分步表单和弹框表单的新建/编辑交互，校验、提交中和防重复提交可见。
3. 用户可查看标准详情、分步详情、附件和操作时间线，并保留从列表进入及返回的上下文。
4. 用户可查看流程图和审批记录，执行同意、退回和驳回提示，动作后状态及审计记录同步更新。
5. 用户可查看柱状图、饼图、折线图和甘特图，图表在明暗主题以及桌面、手机视口中可读且无重叠。
6. 前端构建通过，核心流程完成真实浏览器验收。
7. “组件示例”和“交付示范中心”作为两个独立一级菜单同时显示，菜单路由页面可查看 `ID=500` 和 `/delivery-showcase`。

## 测试与发布

- 必须执行：治理检查、`npm --prefix web run build`、桌面与手机浏览器主流程。
- 上线验证：登录后打开 `/components`，检查列表、新建、详情、图表、甘特和审批。
- 回退：回退新增模块、ECharts 依赖和独立路由；数据库通过后续补偿迁移停用或删除 `ID=500` 菜单记录，不修改已执行的 V25。
- 风险与人工复核人：ECharts 新依赖和前端公共路由变更由前端模块 Owner 复核。
