# 项目计划分组主题色阶

## 目标

项目计划分组保存语义色阶，不保存具体系统主题。分组实际颜色由当前系统主题的 CSS 变量提供，切换系统主题后分组颜色自动同步切换。

## 范围

- 分组颜色选项使用 `brand`、`accent`、`success`、`warning`、`danger`、`muted` 等语义色阶。
- 分组表单的预览颜色读取当前主题变量；科技蓝主题下显示科技蓝色阶，切换其他主题后同步变化。
- 服务端保存和查询语义色阶，非法值拒绝；空值兼容为 `brand`。
- 使用 V42 将上一版误保存的系统主题编码归一为 `brand`，避免旧数据继续表现为固定主题颜色。
- 修复前端提交字段与后端字段链路，保存后刷新项目应返回并显示新色阶。

## 非目标

- 不新增系统主题，不修改主题设置页面。
- 不改变项目权限、租户边界、计划层级和拖放逻辑。
- 不修改已发布 V41，只追加 V42。

## 验收条件

1. 新建或编辑分组选择色阶后保存，接口返回相同 `color_key`，刷新后仍保持。
2. 切换系统主题后，同一分组的色阶语义不变，但实际颜色随主题变量变化。
3. 旧的 `tech-blue` 等主题编码自动归一为 `brand`，不再作为分组颜色编码使用。
4. 空值使用 `brand`，非法色阶由服务端以中文错误拒绝。
