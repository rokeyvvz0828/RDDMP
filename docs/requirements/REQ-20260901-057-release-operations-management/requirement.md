# 投产管理

## 业务目标

新增“投产管理”父级菜单，按当前顶部项目切换栏选择的项目展示和维护投产过程数据。数据按项目独立维护，与既有投产窗口、版本申请解耦。

## 本次实施

- 新增投产管理父级菜单及五个子菜单：投产演练计划、投产时序、投产回退时序、投产问题分析及跟踪、投产组织。
- 投产演练计划维护一套项目演练方案、环境搭建说明和多轮演练记录；轮次支持新增、编辑、删除。
- 投产时序和投产回退时序维护时序标题及明细，页面展示可读的横向时序图，并支持明细新增、编辑、删除和排序。
- 投产问题分析及跟踪维护问题编号、标题、优先级、状态、责任人、发现时间、问题描述、分析结论、处理措施和跟踪记录。
- 投产组织维护无层级投产组，并从当前项目有效成员中向组内添加或移除成员。
- 顶部项目切换后，五个页面重新加载当前项目数据；旧项目数据不得残留在列表、表单或时序画布中。

## 不实施

- 不改变既有配置管理中的投产窗口、版本申请、投产基线、生产版本和审批流程。
- 不将投产管理数据绑定到投产窗口或版本申请；后续关联另行立项。
- 不新增组织层级、系统用户或项目成员；投产组织只引用现有项目成员。
- 不修改已发布 Flyway 脚本；仅追加迁移。

## 验收标准

1. 有权限用户可以看到投产管理父级菜单及五个子菜单；无对应查看权限的页面和接口均不可访问。
2. 当前项目下可以保存演练方案、环境搭建说明，并增删改多轮演练记录；刷新页面数据仍保持。
3. 投产时序和回退时序均能展示明细节点，节点按序号绘制，并可新增、编辑、删除和调整顺序。
4. 问题列表可按关键字、优先级和状态筛选，支持新增、编辑、删除及跟踪信息维护。
5. 投产组织可新增、编辑、删除投产组，可将当前项目有效成员加入或移出组；不能加入其他项目成员。
6. 切换项目后，五个页面的列表、详情、选项和编辑状态都只对应新项目；接口绕过前端传入其他项目 ID 时由服务端拒绝。
7. 后端覆盖正常、参数校验、租户/项目范围、权限、实体不存在和并发版本场景；前端覆盖加载、空、失败、无权限、保存中和重复提交状态。
8. 后端测试、前端构建、Flyway 检查、治理检查、差异检查和桌面/手机浏览器验收按任务范围执行并记录结果。

## 数据和回退

追加 `V123__release_operations_management.sql`，新增演练计划/轮次、时序/时序明细、问题、投产组/组成员表，并幂等写入菜单和权限。应用回退时保留已写入业务数据和迁移历史，可先关闭菜单或回退应用入口，不删除已执行迁移。
