# 动态菜单回归修复

## 业务目标

修复项目级角色权限上线后出现的菜单回归：系统设置中的“权限维护”必须显示正确中文，拥有当前项目任一业务权限的用户必须能看到“项目管理”入口。

## 范围

- 追加 Flyway 补偿迁移，使用与 SQL 客户端字符集无关的 UTF-8 字节写回“权限维护”。
- 修正动态路由筛选，使 `*:access` 导航入口可由同命名空间的具体业务权限激活。
- 补充路由和迁移回归测试。

## 不变量与非目标

- 不修改已发布的 V201，不手工伪造 Flyway 历史。
- 不改变项目成员、项目角色权限和系统角色权限的数据边界。
- 不允许没有任何 `project:*` 权限的用户获得项目管理菜单。
- 不修改前端页面布局、JWT、公开 API 或项目业务表。

## 验收标准

1. 菜单 102 的名称为“权限维护”，UTF-8 字节为 `E69D83E99990E7BBB4E68AA4`。
2. 当前项目权限包含 `project:project:list`、`project:plan:list` 等任一 `project:*` 权限时，动态路由包含 `/projects`。
3. 当前项目没有任何 `project:*` 权限时，动态路由不包含 `/projects`。
4. 系统与其他命名空间菜单仍按原权限规则生成，Security/System 聚焦测试和前端构建通过。
