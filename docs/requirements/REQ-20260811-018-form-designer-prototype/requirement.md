# REQ-20260811-018 表单设计器平台原型

status: ready

## 业务目标

为已确认的“平台自有 DSL + form-create 设计器 + 平台自有渲染器”路线提供一个可运行的前端原型，用于验证统一表单设计器的工作区布局、拖拽交互、属性配置、预览和 Schema 表达方式。

## 本次实施

- 新增独立的表单设计器原型页面和路由。
- 提供常用输入组件的左侧组件区、中央画布和右侧属性面板。
- 支持拖入新增字段、画布内排序、字段属性编辑、设计/预览/Schema 切换和本地重置。
- 使用示例 JSON Schema 展示平台 DSL 的初步形态。
- 复用现有 Element Plus、UI 组件和主题变量，满足桌面及手机视口的基本布局。

## 本次不实施

- 不接入 `biz_form_*` 正式保存 API。
- 不引入或锁定 `form-create` 运行时依赖；本原型只验证交互和 DSL 方向，后续实现阶段再接入设计器适配层。
- 不新增数据库迁移、权限编码、菜单数据或业务模块动态渲染。
- 不修改现有输入项配置页面的业务逻辑。

## 验收标准

1. 通过 `/system/form-designer-prototype` 可打开设计器原型。
2. 组件可拖入画布并生成字段，画布字段可重新排序、选中和删除。
3. 右侧修改字段名称、编码、控件类型、栅格宽度和必填状态后，画布和 Schema 同步更新。
4. 预览视图能按当前字段配置展示可交互表单，Schema 视图能显示当前 DSL。
5. 生产构建通过，手机视口下三栏布局收敛为单列且内容不重叠。

## 回退

删除原型路由、页面和本需求文档即可回退；不涉及数据库和正式业务配置。
