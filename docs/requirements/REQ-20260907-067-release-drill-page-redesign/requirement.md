# 投产演练页面改版

用户要求“重新设计投产演练的页面，功能保持不变”，并确认“窄轮次导航 + 宽演练详情”的推荐方案。仅进行展示和布局改版，轮次弹窗、步骤抽屉及原有业务字段、校验、权限、项目隔离和 CRUD 保持不变。

设计修订见 docs/engineering-control/designs/2026-09-07-release-drill-page-redesign-design.md，修订 1 已获用户批准；随后落盘的实施计划与交接包也经用户回复“确认”批准。按任务前缀控制闭环实施和验收。

- R1：桌面使用窄轮次导航和宽演练详情，保持轮次选择与刷新。
- R2：当前轮次的方案、环境、计划时间、状态和结果清晰分区，保留轮次维护弹窗及所有原字段。
- R3：步骤保持顺序展示和抽屉维护，桌面扩大节点空间，保留步骤原有功能。
- R4：手机改为轮次选择器与纵向步骤，弹层和主题保持可用。
- R5：保留项目隔离、权限、CRUD 请求参数和全部原异常反馈。

产品修改面仅 web/src/modules/release/components/ReleaseDrillExecutionView.vue。不改后端、API、数据库、公共组件、共享 CSS、路由或其他业务页面；不读取 .env；不提交、推送、切分支或重启服务。已有改动保留。

验收按设计的桌面、手机、主题和原业务回归矩阵执行；缺失真实浏览器或接口证据时不得宣称完成。回退仅撤销本任务专项改动。当前账本前缀 req-20260907-067-release-drill-page-redesign，实际阶段以本任务 state.json 为准。
