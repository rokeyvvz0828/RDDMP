# 业务对象页面设计器实施计划

## T1 任务与契约

- 新增 V37 追加字段及服务端归一化校验。
- 扩展前端类型、接口 payload 和 Mock 视图。
- 将现有设计器重构为页面集合工作区，保留旧路由和字段引用 API。

## T2 验证

- 执行 system 模块测试、前端构建、治理和 Flyway 检查。
- 重启已有 JDK 17 服务，检查页面集合、页面角色、表单模式和字段保存链路。
- 在 375x812、390x844、430x932、1280x800 验证设计器无页面级横向溢出。

## 停止条件

- 历史 view_type 无法归一化。
- 列表页可保存不属于业务表单字段集合的字段。
- 新建/编辑以外页面出现可选表单模式。
- 页面树或属性面板导致移动端页面整体横向溢出。
