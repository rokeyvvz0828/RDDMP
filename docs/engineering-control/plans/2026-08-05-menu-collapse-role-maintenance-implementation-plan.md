# 菜单折叠对齐与用户角色维护实施计划

> 执行要求：按已批准设计实施，并在代码修改后运行前端构建与浏览器行为检查。

**目标：** 修复折叠菜单图标对齐，并把用户角色维护改为独立弹窗和独立保存流程。

**架构：** 只修改现有前端系统页面和全局菜单样式；角色继续复用现有用户角色 API，不改变后端契约。

**技术栈：** Vue 3、TypeScript、Element Plus、现有组件和 Axios API 封装。

## 全局约束

- 保持单租户、中文界面和现有权限边界。
- 不修改用户资料保存接口，不把角色保存重新耦合回资料保存。
- 折叠菜单的尺寸必须稳定，不能因激活、悬浮、一级菜单或子菜单变化而移动。

### T1：折叠菜单几何对齐

**需求映射：** 菜单收缩后图标上下对齐。

**文件：**
- 修改：`ccb-web/src/styles.css`

**步骤：**

1. 为折叠菜单项和子菜单标题统一设置 `box-sizing`、`display:flex`、`align-items:center`、`justify-content:center`、固定宽高和零内边距。
2. 统一 `.el-icon` 的宽度、行高、边距和伸缩行为，覆盖 Element Plus 默认规则及 compact 密度规则。
3. 运行 `npm run build`，确认样式选择器不引入编译错误。

**验收：** 折叠菜单各可见图标的中心点处于同一内容列；展开/收缩动画结束后无横向或纵向跳动。

**回滚：** 删除本任务新增的折叠菜单样式覆盖。

### T2：独立角色维护弹窗

**需求映射：** 用户角色维护操作简化且与资料保存解耦。

**文件：**
- 修改：`ccb-web/src/views/ModuleView.vue`

**步骤：**

1. 新增角色弹窗状态、当前用户状态和角色保存状态。
2. 新增打开角色维护函数，加载角色选项和用户当前角色。
3. 新增独立保存函数，只调用 `saveUserRoles`，成功后关闭弹窗并提示。
4. 在用户列表操作列增加“角色”按钮。
5. 从用户编辑抽屉中移除角色多选字段及资料保存时的角色保存调用。

**验收：** 修改用户资料不会触发角色保存；角色弹窗可以在不打开资料抽屉的情况下读取、修改和保存角色。

**回滚：** 恢复抽屉中的角色选择字段和原有角色保存逻辑。

### T3：构建和运行验证

**文件：** 无新增业务文件。

**命令：**

- `npm run build`（工作目录：`ccb-web`）
- 浏览器打开用户管理，验证收缩菜单、角色弹窗、角色加载和保存。

**停止条件：** TypeScript 编译失败、角色保存请求携带用户资料更新、菜单仍出现可复现错位。

**最终证据：** 构建成功输出、浏览器行为结果、工作区变更清单。

## 任务依赖

`T1` 与 `T2` 可独立修改，`T3` 依赖两者完成。
