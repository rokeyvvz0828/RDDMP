# 表单设计器平台原型实施计划

> 执行要求：使用 `$control-engineering` 逐任务实施。该计划只覆盖前端本地原型，不扩大为正式动态表单能力。

**目标：** 在当前 Vue 3 + Element Plus 工程中交付可观察的表单设计器交互原型。

**架构：** 新增独立原型页面和路由，使用浏览器原生拖放维护内存中的平台 DSL 示例；设计视图、预览视图和 Schema 视图消费同一份字段状态。正式 API、数据库和 form-create 依赖保持不变。

**技术栈：** Vue 3 `<script setup>`、TypeScript、Element Plus、现有 UI 组件和 CSS 主题变量。

## 全局约束

- 只实现原型，不修改 `biz_form_*` API、迁移和正式输入项配置保存逻辑。
- 复用现有交付示范中心的页面密度、主题变量和移动端规则。
- 禁止保存任意脚本、SQL 或第三方原始配置；Schema 只用于展示。
- 只修改本需求授权的前端、文档和当前 `.ai-control` 目录。

## 控制种子

- 被控边界：前端原型页面和本地内存 DSL。
- 状态变量：当前视图、字段顺序、选中字段、属性值、Schema 文本。
- 输入：组件拖入、字段排序、属性编辑、视图切换和重置。
- 输出：画布、预览表单、Schema 文本和浏览器可见布局。
- 传感器：Vite 构建、治理检查、浏览器 DOM/截图和 390px 视口观测。
- 执行器：Vue 响应式状态、原生拖放事件和路由导航。
- 扰动：浏览器刷新、移动端窄屏、字段删除和空画布状态。
- 假设：现有 Element Plus 全局注册和 Vite 热更新可用，需由 T2 验证。
