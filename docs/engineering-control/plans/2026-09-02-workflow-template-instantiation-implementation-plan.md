# 工作流模板实例化实施计划

**目标：** 分离全局结构模板与可执行流程，并提供从模板创建项目流程的安全路径。

**约束：** 不修改 V134；不改变业务模块场景规则；模板绝不进入运行时；项目授权由后端执行；存量平台流程保持可执行。

## T1：迁移与后端范围控制

**需求映射：** R1-R6

- [ ] 增加模板范围聚焦测试，先覆盖具体人员拒绝、生命周期拒绝和启动匹配优先级。
- [ ] 追加 V135，将 `GLOBAL` 迁移为 `PLATFORM` 并修改默认值。
- [ ] 定义列表支持 `scopeType`；模板发布、恢复、启动和业务目录统一拒绝或排除。
- [ ] 模型校验接受模板占位，范围校验保证占位只出现在 `TEMPLATE`。
- [ ] 运行工作流聚焦测试与模块测试。

**回滚：** 回退 Java，保留 V135；回退版本必须兼容 PLATFORM。

**停止条件：** 发现业务模块直接依赖 `GLOBAL` 字面值且无法兼容映射，或模板必须进入 Flowable 编译。

## T2：前端分区与模板实例化

**需求映射：** R2-R8

- [ ] API 类型支持三类范围和列表过滤。
- [ ] 定义页增加三个分区，默认当前项目流程并保持服务端分页。
- [ ] 模板编辑器只显示发起人/结构占位，不请求或展示具体人员角色。
- [ ] 增加“从模板创建项目流程”，复制图并清空人员配置。
- [ ] 运行前端构建、全量后端、治理、范围、迁移和浏览器验证。

**回滚：** 回退 Vue/TypeScript；后端模板约束继续保护数据。

**停止条件：** 当前图模型无法无损复制，或项目上下文缺失时仍可创建项目流程。

## 依赖与证据

`T1 -> T2` 串行。证据包括聚焦测试、模块测试、全量测试、真实 MySQL V135、前端生产构建、治理范围检查，以及桌面与三个手机视口的浏览器记录。
