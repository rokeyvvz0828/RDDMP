# 投产方案时序指令与抽屉交互实施计划

## T1：方案契约与持久化

修改投产方案模型、Store、Service、前端 DTO 和追加 V128 迁移，新增正向/回退时序名称并回填历史方案默认值。补充服务测试覆盖新建默认名称和更新名称。

## T2：方案时序抽屉与指令文案

在方案页为两个时序增加抽屉摘要入口和抽屉内容，支持名称保存、多个指令新增编辑删除；方案指令相关文案统一改为“指令”，保持时间范围和现有 API payload。

## T3：环境抽屉与页面清理

将环境新增/编辑改为抽屉，移除投产管理壳页面的主标题和描述，补充桌面/移动布局样式。

## T4：验证

执行前端构建、投产后端测试、`git diff --check` 和真实浏览器验收，检查项目切换、权限、并发版本和页面溢出。
