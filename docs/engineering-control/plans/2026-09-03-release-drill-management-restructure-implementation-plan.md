# 投产演练管理模型重构 实施计划

## 任务包

1. T1 数据库与菜单：追加 V127 新表、索引、旧数据回填、新菜单/权限、旧菜单逻辑下线和演示数据。验收为迁移检查通过、旧记录可关联默认方案/环境、重复执行幂等。
2. T2 后端契约：扩展 model/store/service/controller，新增方案、环境、演练步骤 CRUD，轮次强制方案/环境关联，问题支持轮次；补充边界与安全测试。验收为模块测试和实体越权/跨项目断言通过。
3. T3 前端流程：更新 API 类型、路由、页面壳和投产页面，移除旧时序入口，实现方案/环境/演练/问题关联的加载、空、失败、提交中、只读和移动端状态。验收为构建通过和浏览器路径可达。
4. T4 集成观测：运行治理、范围、迁移、构建、测试和浏览器验收，记录问题；发现偏差回到对应任务修复后复验。

## 依赖与回退

T1 -> T2 -> T3 -> T4 串行，原因是数据库和后端契约分别是前端消费者的前置事实。每个任务按文件范围回退，不删除已执行迁移。

## 共享不变量

租户/项目隔离、有效项目成员授权、实体归属、逻辑删除、审计字段、乐观锁、旧接口兼容、动态菜单权限一致、响应式无页面级溢出。

## 采样点

- T1 后：Flyway 静态检查和只读 schema/菜单查询。
- T2 后：Maven 测试、跨项目引用和权限测试。
- T3 后：Vite 构建、源码路由检查和浏览器 DOM/网络/控制台/四视口。
- T4：完整治理、范围和收敛门禁。
