# 测试管理：公告板工程设计

## 文档状态

- 修订：3
- 状态：已确认
- 用户确认依据：用户要求“根据需求和 demo，完成测试公告板模块，全部完成所有功能”，并回复“确认”；后续确认公告板采用管理配置标题层级和交付示范中心式页签，且标题区不放右侧操作。

## 目标

在四个测试大类的默认入口交付按“大类 + 当前全局项目”隔离的公告板；所有有阅读权限的角色可阅读当前公告，测试经理及以上可在同页维护全部历史公告。

## 已确认产品行为

- 页面固定为“当前公告 / 公告管理”横向双 TAB，不发生页面跳转；公告管理 TAB 仅在服务端授予管理权限时渲染。
- 不新增页面级项目选择器，只消费全局项目上下文；未选项目只显示“请先选择项目”。
- 当前公告显示全部置顶公告并按置顶时间倒序；无置顶时展示最新一条；无记录时显示空态和管理者专属的“发布第一条公告”。
- 公告为项目级，项目内所有系统共用；无有效期。
- 管理列表支持标题、发布人、发布时间过滤，固定每页 20 条；列出标题、纯文本摘要、发布人、发布时间、置顶、附件数及查看/编辑/置顶/删除操作。
- 编辑窗宽 720px：标题（100 字必填）、正文（必填）和不限数量附件；正文支持加粗、斜体、段落、列表、表格、链接和内嵌图片。关闭未保存内容必须确认。
- 查看使用 640px 抽屉；附件展示名称、大小、上传时间和下载；删除确认提示附件将级联删除且不可恢复。

## 公告板视觉一致性（修订 2）

- 页面标题复用管理配置的 `UiPageHeader`：眉标为“测试管理”，标题为“<测试大类> · 测试公告板”；不显示标题说明，也不在标题区放置发布、刷新等操作。
- “当前公告 / 公告管理”不再使用默认下划线页签，改为交付示范中心 `delivery-module-nav` 同类的紧凑导航：主题色选中态、面板背景、边框与圆角；当前公告和公告管理分别配合阅读、管理语义图标。
- 当前公告内容和公告管理内容各自放入与平台一致的面板容器，沿用 `--panel-bg`、`--line`、`--brand`、`--muted` 等语义主题变量；不引入硬编码主题色。
- 手机端标题允许换行，导航在局部横向容器内滚动；列表维持现有移动适配策略，页面主体不产生横向溢出。

## 列表交互与密度基线（修订 3）

- 公告管理列表必须复用交付示范中心同样的 `UiDataTable` 封装，不另建局部表格壳；核心字段支持本页排序，数据列支持拖拽调整列宽，操作列固定在右侧且不可拖拽。
- 未排序列不显示排序方向图标；仅排序生效的列显示方向，以免干扰表头扫描。标题、发布时间、是否置顶和附件数使用足以展示中文表头与默认内容的列宽，表头不换行。
- 列表使用紧凑密度：标题列默认 260px、发布时间 132px、是否置顶 96px、附件数 80px；标题和状态标签不作人为省略。较窄视口允许表格区域横向滚动，不使页面主体溢出。
- 操作仅保留编辑、置顶/取消置顶、删除三个无背景图标按钮；有 Tooltip 与 aria-label，间距保持紧凑。

## 实施边界

- 测试管理拥有公告、公告附件映射和操作审计数据；Flyway 仅新增 V124，不改 V123 或平台表。
- 平台附件模块保持只读。测试管理仅依赖其已公开的 `AttachmentGateway`、`AttachmentAccessPolicy` 与前端上传/下载契约；在本模块注册 `TEST_ANNOUNCEMENT` 访问策略，因此下载仍由平台统一鉴权。
- 富文本使用 wangEditor 5 官方 Vue 3 组件（`@wangeditor/editor` 与 `@wangeditor/editor-for-vue@next`），提供成熟的表格、链接、列表和图片编辑体验；前端以现有附件接口接管图片上传，服务端继续白名单净化输出 HTML。
- 菜单读权限复用现有 dashboard 权限；V124 追加 create/update/delete 权限并仅向初始管理员授予。组织可通过既有角色权限管理将该权限分给测试经理及以上。

## 数据与接口

- `tm_test_announcement`：租户、大类、项目、标题、正文、置顶时间、首次发布人/时间、最后编辑人/时间、软删除审计。
- `tm_test_announcement_attachment`：公告、附件 ID、附件类型（`INLINE`/`FILE`）与排序；平台附件绑定业务类型 `TEST_ANNOUNCEMENT`、业务键为公告 ID。
- `tm_test_announcement_audit`：发布、编辑、置顶、取消置顶、删除的操作人、对象、时间和摘要。
- API 固定在 `/api/test-management/announcements/{domain}`：`current`、分页列表、详情、创建、更新、置顶、删除；所有查询和写入由服务端从认证用户取租户和操作人。

## 权限与错误处理

- 阅读接口使用 dashboard 阅读权限；维护接口逐项要求 dashboard 的 create/update/delete 权限，不能依赖前端隐藏。
- 访问策略验证公告所属租户、测试大类、项目和 dashboard 阅读权限；跨项目、跨大类、无权限附件一律拒绝。
- 附件保存前校验单文件不大于 50MB、归属当前用户的临时附件以及重复 ID；删除附件/公告同步删除映射并调用平台受控删除。
- 任何提交中的按钮禁用；请求失败保留表单内容并显示可恢复错误。

## 验证策略

- JUnit 覆盖范围隔离、标题/正文校验、置顶兜底、编辑发布时间、权限、附件和 HTML 净化。
- Maven 测试、Vite 构建、Flyway 与治理检查；本地 MySQL API 冒烟及真实浏览器桌面/移动验收当前公告、管理、创建、编辑、置顶、删除、未选项目和附件路径。

## 风险与回退

- 迁移与绑定附件已经提交后不可物理回退；应用代码回退仍保留数据和附件，重新部署即可恢复读取。
- 富文本编辑器依赖 wangEditor 官方 Vue 3 组件；复杂 Word 粘贴样式仍由服务端净化，不影响规范要求的允许标签。
