# 项目级可配置计划阶段设计

## 决策

阶段从全局 `PLAN_PHASE` 参数下沉为 `pm_project_stage` 项目级实体。阶段 `stage_code` 在项目内稳定唯一，计划和阶段计划继续保存 `phase`，其有效性由当前项目阶段表校验；阶段名称由项目阶段表返回。

## 状态与约束

- 新项目初始化七个默认阶段，既有活动项目由 V83 补齐缺失默认阶段。
- `has_master_plans` 是只读派生状态，按项目和阶段统计 `parent_id = 0` 的有效计划。
- 阶段有主计划时不能改名、改序或删除；所有写操作都由服务端执行项目和租户范围校验。
- 阶段删除只软删除阶段行，不删除计划；由于有主计划的阶段不能删除，删除后的阶段不再被计划写入。

## 前端边界

项目设置显示阶段维护列表，未锁定阶段提供编辑、上移、下移、删除，提供新增阶段入口；锁定阶段显示“已有主计划，无法修改或删除”。项目设置表单与项目计划阶段在桌面端横向两列展示，窄屏自动改为单列。计划时间轴使用项目详情返回的 `plan_stages`，不再依赖全局计划阶段选项。

## 非目标

风险页面仍使用全局 `PROJECT_PHASE`，不改公共 UI 组件、不改权限模型、不改已发布迁移。
