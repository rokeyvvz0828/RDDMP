# 项目计划编号与项目日历设计

## 目标与边界

本次变更继续沿用 `platform/system` 项目服务和 `ProjectView.vue` 单菜单工作台。项目编号仍由用户创建时填写；新增的编号规则只负责计划编号。项目日历从项目详情已有的计划日期派生，不增加日历持久化模型。

## 数据与规则

- `pm_project.plan_number_rule` 保存计划编号规则，默认 `{PROJECT_CODE}-P{SEQ:3}`。
- `pm_project_plan.plan_code` 保存计划编号，历史数据允许为空。
- `{PROJECT_CODE}` 使用项目编号，`{SEQ}` 使用项目级递增序号，`{SEQ:n}` 左侧补零，日期占位符使用创建时日期。
- 创建计划时服务端读取项目规则，在项目行锁内分配序号并生成编号；唯一索引 `(tenant_id, project_id, plan_code)` 防止同一项目重复。
- 编辑计划不重编号，删除后的编号不复用。

## 接口

- 项目详情和工作台项目对象新增 `plan_number_rule`、`plan_progress`。
- 新增 `PUT /api/project/{projectId}/settings`，请求字段为 `plan_number_rule`，返回项目详情。
- 项目计划对象新增 `plan_code`。

## 前端

- 项目详情新增“项目设置”页签，规则输入提供占位符说明和保存状态。
- 计划树新增“计划编号”列。
- 卡片进度使用 `plan_progress`。
- 概览新增月历：可切换月份，按计划起止日期渲染计划条目；点击条目切换到项目计划页签。

## 错误与兼容

- 规则为空时使用默认规则；规则包含未知占位符、缺少序号占位符或长度超限时返回中文 400 错误。
- 历史计划的空编号只显示“未生成”，不回溯生成，避免改变历史数据。
- 项目设置保存必须经过现有项目权限和项目负责人校验。
