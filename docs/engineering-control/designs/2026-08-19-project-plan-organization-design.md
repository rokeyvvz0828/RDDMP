# 项目计划与组织架构设计

## 交互设计

项目概览主计划甘特图负责选择阶段；阶段计划图展示所选阶段的阶段计划行，并在其区域提供新增主计划。阶段计划通过阶段编号和同阶段序号展示，不再要求用户填写名称。项目详情新增“项目组织架构”页签，成员和角色以两个区块呈现，复用现有表格、抽屉、权限和刷新逻辑。

## 契约与数据

阶段计划编号由服务端按项目和阶段生成，并在事务内锁定序号，避免并发重复。前端只提交阶段，不提交阶段计划名称。既有成员、角色接口和数据结构保持兼容。

## 状态与验收

新增、保存、刷新、空数据、错误和无权限状态沿用现有项目详情状态。桌面端保持图表局部布局，移动端使用已有局部滚动边界，不引入页面级横向滚动。
