## 目标

需求管理平台运行面不再出现客户专有术语「蒙商」「金科」，统一替换为通用术语「同业」「我方」（含组合词），且不产生任何接口或字段标识符破坏性变更。

## 替换规则

- `蒙商 → 同业`、`蒙商银行 → 同业银行`、`金科 → 我方`（文本与枚举值机械替换）。
- 差异类型：`金科有-蒙商无 → 我方有-同业无`、`金科有-蒙商手工 → 我方有-同业手工`、`蒙商有-金科无 → 同业有-我方无`、`双方作法有差异` 不变。
- 变更结论：`蒙商立项完成 → 同业立项完成`。
- 导入兼容：模板表头展示新术语；解析时旧表头映射为同一字段（新旧并存）。
