# 测试报告与分析统计设计

用户已确认 V1.6 模块 8、9 的字段级规格和 demo，本设计将其落实为当前分支的敏捷实现边界。

- 复用：全局项目上下文、测试范围的紧凑树/`UiDataTable`/可调列宽、`TestManagementFormDialog`、WangEditor 与既有导出下载模式。
- 报告：以项目或参测物理子系统为树节点，生成时固化六章节统计快照。报告对象维持当前版本，重生成递增版本；补充说明按版本与章节保存，不改变快照。
- 统计：提供范围覆盖、执行进度、缺陷分布、人员工作量四个预置报表；个人/共享配置保存至模块表；筛选后可查看表格、柱状/饼状摘要、导出 XLSX 或 PNG，并按轮次保存可追溯快照。
- 数据：V142 追加报告、版本、章节补充、统计配置、统计快照和审计表；查询仅聚合测试管理拥有的范围、案例、执行、缺陷和配置数据。
- 权限：所有读取接口执行大类项目/参测系统范围验证；报告生成/删除、统计共享发布/快照由服务端菜单动作权限保护。
- 交互：桌面为 `248px + 内容区`；移动端改为垂直树后内容，表格保持横向滚动；所有编辑均使用居中弹窗，报告正文区最少 15 行。
