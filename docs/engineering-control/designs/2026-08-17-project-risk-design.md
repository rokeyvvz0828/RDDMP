# 项目风险设计

## 页面结构

项目详情页签顺序为：项目概览、项目计划、项目风险、项目成员、项目角色、项目设置。风险页签使用列表作为入口，新增/编辑使用抽屉，表单分为三块：问题上报、进展跟踪、升级与解决。

## 数据契约

风险记录归属项目，编号由项目设置的 `risk_number_rule` 生成，支持 `{PROJECT_CODE}`、`{SEQ}`、`{SEQ:n}`、`{YYYY}`、`{MM}`、`{DD}`。枚举字段保存参数键并返回对应显示名称；组织保存组织 ID 并返回组织名称。

## 默认参数示例

新增迁移提供风险紧急程度（高/中/低）、上报问题级别（一级/二级/三级）、当前状态（待处理/处理中/已解决/已关闭）、关注等级（高/中/低）、升级级别（已升级/未升级）、当前问题级别（重大/严重/一般）。项目阶段复用现有项目阶段参数。

## 权限与安全

风险 API 复用项目成员可见范围；服务端使用独立的 risk 资源动作权限和项目实体授权。前端只用于隐藏不可用操作，不能代替服务端校验。

## 响应式

桌面端风险列表保持局部横向滚动，抽屉在 760px 以下接近全宽、表单单列；三段表单标题固定可识别，日期、枚举、组织字段不超出父容器。
