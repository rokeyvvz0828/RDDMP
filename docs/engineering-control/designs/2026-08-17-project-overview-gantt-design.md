# 项目概览甘特图设计

## 用户路径

用户进入项目管理，打开一个项目详情并停留在“项目概览”。页面展示项目摘要、统计图和两个项目排期甘特图；图表只读，计划维护仍在“项目计划”页签完成。

## 页面结构

- 保留项目说明和现有统计图。
- 移除“项目日历”卡片及其按天查看交互。
- 新增“主计划甘特图”：每个主计划一行，时间轴使用月份，条形颜色表达计划状态，条内保留进度。
- 新增“子计划甘特图”：每个主计划先显示一行作为分组标题，随后显示其子计划；时间轴使用周，子计划条形颜色表达计划状态。
- 图表使用独立的 `.project-gantt-scroll` 局部滚动容器，避免页面整体横向滚动；移动端减少时间轴标签密度。

## 数据与绘制

- 数据来源沿用 `selectedProject.plans`，主计划通过 `parent_id` 为空/0 识别，子计划通过 `parent_id` 关联。
- 缺少有效开始和结束日期的计划不进入甘特图；整个图表没有可绘制数据时显示空状态。
- 使用现有 ECharts 和交付示范中心的 custom series 绘制模式，不新增图表依赖。
- 月轴范围覆盖主计划日期的首月到末月；周轴按周一对齐，覆盖子计划及其主计划日期范围。

## 状态

加载状态由现有项目详情遮罩承载；无数据使用 `el-empty`；日期异常或缺失只影响该计划绘图，不阻断概览其他内容。主题颜色通过 `--brand`、`--success`、`--warning`、`--danger`、`--muted` 和 `--line` 获取。

## 移动端

甘特图保留任务名称列并在图表自身容器内横向滚动，页面根节点不新增固定最小宽度。小屏只显示必要的月/周刻度，条形和任务名称仍可读。
