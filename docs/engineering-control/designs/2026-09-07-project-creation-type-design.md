## 行为与契约

R1：新建和编辑项目可维护创建类型，仅新建/续建。新建默认NEW，选择CONTINUATION后保存、详情读取、编辑回显一致；显式空值或非法值由服务端拒绝且不写库。

R2：已有项目统一新建，之后可编辑为续建。追加迁移使存量项目creation_type为NEW；旧客户端创建不传时默认NEW；更新不传时保留原值。

R3：顶部当前项目及下拉选项展示创建类型，保存后同步。桌面侧栏/顶栏及移动三个选择入口均显示名称和类型标签；保存成功后当前项目标签同步；不改变选中项目、不触发切换确认或页面重载；刷新后保持正确标签。

R4：保持原权限、审计、切换与响应式可用性。读写继续认证、RBAC、租户/实体权限与原审计；四种规定视口及明暗主题下标签可见、长名称不遮挡，表单提交/取消可达；加载、空、失败、无权限、提交中及取消切换行为保持。

字段 creation_type：NEW=新建，CONTINUATION=续建。新建默认NEW；编辑回显原值。显式空值或非法值返回原业务错误模型的400，不写库。旧客户端创建省略默认NEW，更新省略保留原值。字段不改变项目status、项目阶段或投产规则。
