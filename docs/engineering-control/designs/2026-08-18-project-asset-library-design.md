## 目标与成功信号

在数据迁移业务中建立以正式项目为数据边界的非结构化资产库。项目成员能够按服务端权限完成目录、上传、查询、下载、更新元数据、预览、分享、收藏、标签、备注、审核、回收站和迁移包操作；平台统一承担项目上下文、对象存储、病毒扫描、工作流和审计边界。

成功信号包括：正式项目成员范围可被多个业务复用；最大 5GB 文件可以断点续传并在扫描通过后使用；资产操作不能跨租户或跨项目；强约束外链可撤销且可审计；永久回收站可恢复和受控彻底删除；统一页面在桌面和指定手机视口完成同等任务。

## 使用者与场景

- 平台管理员：配置平台 RBAC、查看安全和审计结果，不直接替代项目负责人处理业务资产。
- 项目负责人：维护项目、项目管理员和成员，管理项目内全部资产。
- 项目管理员：维护成员、目录和资产，不转移项目负责人。
- 项目成员：查看全部审核状态，按平台权限上传、维护本人草稿并使用已授权资产。
- 只读成员：查询、预览、下载和收藏，不执行写操作。
- 审核人：在项目可见和工作流任务关系同时成立时办理审核。
- 安全管理员：处理隔离文件和扫描异常，不获得无关项目的普通业务权限。
- 外链接收者：使用有效令牌、提取码和剩余次数执行被明确授予的预览或下载。

## 必须需求与验收条件

### R1 正式项目上下文

项目编号租户内唯一，项目角色固定，项目归档只读；公开契约可提供项目摘要、成员关系和数据范围判断。非成员、跨项目和跨租户访问不泄露对象存在性。

### R2 安全持久附件

支持最大 5GB、每用户 20 个并发上传、分片重试和断点续传；服务端计算 MD5/SHA-256；ClamAV 通过前不可预览、下载、审核或分享；MinIO 对象键和凭据不对业务或客户端持久暴露。

### R3 资产核心

文件编号为 UUID，内容不可覆盖；查询支持项目、编号、名称、目录、标签、审核状态、上传用户和时间；目录、标签、追加备注、收藏、审核、强约束外链和永久回收站遵循已确认状态与权限规则。

### R4 传输与界面

普通上传/下载和 ZIP64 迁移包导入导出均可观察进度与部分失败；统一页面完成全部资产操作，并在桌面、`375x812`、`390x844` 和 `430x932` 视口无页面级横向溢出。

## 不变量与约束

- 有效权限始终等于平台 RBAC、项目角色范围和实体状态允许操作的交集。
- 前端显隐、项目选择、用户字段、对象键、文件摘要和外链计数均不作为可信授权输入。
- 业务模块不读取其他模块私有表；平台模块不依赖具体业务实现。
- 文件内容不可通过更新接口替换；内容变化生成新的 UUID 文件。
- Flyway 迁移只追加；生产回退不执行 `DROP` 或无审批对象清理。
- 测试数据使用虚构项目、用户、文件和测试病毒样本，不使用生产数据。

## 非目标

- 完整项目计划、阶段、预算、里程碑、风险和工时管理。
- 全文检索、OCR、在线编辑、二进制覆盖、文件版本和跨租户去重。
- 永久匿名链接、任意远程 URL、公开 MinIO 桶或外部对象存储直连。
- 把迁移包作为数据库备份，或迁移成员权限、分享凭据、审批结论和审计日志。

## 方案比较与选择

### 已选：独立业务模块与平台文件能力

`ccb-project` 拥有项目主数据和成员范围；`ccb-attachment` 拥有分片上传、对象、扫描、预览和下载；`ccb-data-migration` 拥有资产目录、协作、审核、外链、回收站和迁移任务。该方案边界清楚，后续业务可以复用项目和附件能力，代价是需要公共契约审批和跨模块回归。

### 未选：全部放入数据迁移模块

初期文件较少，但会复制项目、存储和安全能力，使未来业务无法复用并扩大单模块风险。

### 未选：把资产库放入平台附件模块

附件复用直接，但会让目录、标签、审核和项目规则污染平台层，违反平台/业务边界。

## 架构边界与组件职责

```text
ccb-data-migration -> ccb-project 公开契约
ccb-data-migration -> ccb-attachment 公开契约
ccb-data-migration -> ccb-workflow 公开契约
ccb-project / ccb-attachment -> common、infrastructure、security
ccb-boot -> 装配全部模块
web data-migration module -> 独立 API 封装与 Project Context Store
```

- `ccb-project`：项目、成员、状态和数据范围判断。
- `ccb-attachment`：上传会话、MinIO 对象、摘要、ClamAV、预览、Range 下载、配额和对象清理。
- `ccb-data-migration`：资产、目录、标签、备注、收藏、审核绑定、外链、回收站和传输任务。
- `ccb-workflow`：按公开契约启动和办理资产审核，数据迁移模块根据稳定生命周期事件更新审核状态。
- 前端模块：统一资产工作入口，不拼接后端地址、对象键或 kkFileView 地址。

## 接口、数据和状态流

### 项目状态

项目采用 `ACTIVE` 和 `ARCHIVED`。归档后资产只读并撤销外链；恢复后原成员关系重新参与授权。

### 附件状态

`UPLOADING -> SCANNING -> READY`；扫描异常进入 `SCAN_FAILED`，风险文件进入 `QUARANTINED`。隔离内容不可访问，仅上传者、项目管理员和安全管理员可见最小风险元数据。

### 资产状态

- 审核：`DRAFT -> PENDING -> APPROVED`，驳回进入 `REJECTED`，撤回后回到草稿。
- 生命周期：`ACTIVE -> RECYCLED -> PURGED`。
- `PENDING` 冻结名称、目录、标签和备注；文件内容始终不可覆盖。

### 上传流

```text
选择项目和目录
-> 校验权限、配额和并发数
-> 创建上传会话并签发短期分片地址
-> 浏览器直传 MinIO
-> 服务端完成对象并计算 MD5/SHA-256
-> ClamAV 扫描
-> READY 后创建 UUID 资产草稿
-> 返回重复文件提示和资产结果
```

### 核心数据

- 项目：项目、项目成员。
- 附件：附件对象、分片上传会话及可重试清理状态。
- 资产：资产、目录、标签、标签关联、追加备注、收藏、分享、访问日志、工作流绑定和传输任务。
- 外链只保存令牌摘要、BCrypt 提取码、有效期、访问上限、原子访问计数、预览/下载授权和撤销状态。

### 迁移包

ZIP64 包含目录、文件、标签、追加备注和 `manifest.json`。清单保存 UUID、相对路径、大小、类型、MD5 和 SHA-256，不包含收藏、分享、成员、审批结论或审计。导入重新扫描并创建草稿；UUID 冲突生成新 UUID 并记录映射，同路径目录合并，单文件失败不回滚其他成功文件。

## 错误、降级与恢复

- 超限返回 `413`，状态或乐观锁冲突返回 `409`，扫描/清单错误返回 `422`，外链限流返回 `429`。
- 无权限、跨租户、跨项目和不可见对象不泄露对象是否存在。
- 上传完成、取消、批量删除、分享创建和传输任务支持幂等键。
- 批量接口返回成功数、失败数和逐项错误；异步任务持续保存进度和重试入口。
- ClamAV 或 kkFileView 不可用时文件保留可恢复状态，不能绕过扫描或把构建成功误作运行可用。
- 过期上传会话清理未完成分片；永久回收站不自动清理。

## 安全、性能、兼容性与运维

### 安全

- 外链使用至少 256 位随机令牌、必填提取码、最长 7 天、访问次数、预览/下载分权、撤销和按令牌/来源限流。
- 扩展名、声明 MIME 和内容特征联合校验；迁移包限制文件数、展开大小、压缩比和目录深度，防止路径穿越和压缩炸弹。
- 审计覆盖项目、成员、上传、扫描、查询、预览、下载、审核、分享、标签、备注、回收站和传输任务。

### 性能

- 单租户 100 万文件、单项目 10 万文件、目录 1 万个。
- 单批最多 1,000 文件，每用户最多 20 个并发上传。
- 项目资产首屏查询 `p95 <= 800ms`，目录子节点查询 `p95 <= 300ms`，外链验证 `p95 <= 500ms`，均在受控验收环境测量。
- 目录采用懒加载；上传、下载、摘要和 ZIP64 全程流式处理，批量任务不一次载入全部对象。

### 兼容与运维

- 保留现有临时文件预览行为；新持久附件入口使用独立契约。
- 配置租户/项目配额、上传并发、会话过期、扫描超时、外链限流和后台任务监控。
- 应用回退保留新增表和对象，先关闭菜单、上传、外链和任务调度，再回退装配。

## 前端设计

桌面使用项目选择器、路径面包屑、左侧懒加载目录树和右侧资产表格。页签为全部文件、我的收藏、待我审核、传输任务和回收站；主操作为上传文件，低频操作进入更多菜单。上传队列持续展示分片进度、暂停、继续、取消、重复提示、扫描和重试。

移动端使用目录抽屉、紧凑文件卡片和最高 `88vh` 的可滚动底部操作层，不压缩桌面表格，不依赖拖拽。桌面拖拽上传和拖拽换目录必须有文件选择器与目录选择器作为等价替代。

复用 `UiToolbar`、`UiDataTable`、`UiEmptyState`、`UiFilePreview`、现有树模式、API 错误处理和语义主题变量。新增样式仅限资产目录、文件单元格和分片上传队列。所有页面覆盖加载、空、失败、无权限、归档只读、上传/扫描/隔离、审核、部分成功和重复提交状态。

## 风险与回退原则

- 公共项目/附件/工作流契约错误会影响多个消费者：先固定契约并执行消费者回归。
- 大文件、扫描和 ZIP 可造成资源耗尽：流式处理、配额、并发上限、超时和异步任务必须同时实施。
- 匿名外链可能泄露内部资产：令牌摘要、提取码、有效期、次数、限流、撤销和审计全部为硬门禁。
- 数据库和对象状态可能不一致：使用可重试状态、幂等动作和补偿任务，不在失败时静默丢失元数据。
- 回退按 `029 -> 028 -> 027 -> 026` 逆序执行；保留数据库、对象和审计，不执行生产物理删除。
