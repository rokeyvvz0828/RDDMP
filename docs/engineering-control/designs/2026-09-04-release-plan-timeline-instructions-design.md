# 投产方案时序指令与抽屉交互设计

## 方案

`rel_release_plan` 增加 `normal_timeline_name` 与 `rollback_timeline_name` 两个字段。方案查询 DTO 返回两个名称，方案新增时由服务端写入默认名称，方案编辑和时序抽屉名称保存复用方案更新接口。方案指令仍使用现有 `rel_release_plan_item`，按 `item_type` 隔离正向和回退数据。

方案页保留方案列表，右侧详情只展示两个时序摘要入口。点击入口打开对应的右侧 `el-drawer`，抽屉内显示名称表单、横向指令轨道和新增/编辑/删除操作。名称保存与指令保存分开提交，均沿用现有项目权限和 rowVersion。

环境页面把已有表单容器从 `el-dialog` 替换为右侧 `el-drawer`，字段和保存 payload 不变。投产管理壳页面移除重复主标题，保留项目解析和路由内容。

## 约束

- 不复用项目级独立时序 API，避免不同方案共享指令数据。
- 不改变演练轮次、演练步骤和权限契约。
- 时序轨道只在抽屉内容区域横向滚动，页面本身保持无横向溢出。
- 移动端抽屉宽度使用 `min(..., 94vw)`，底部操作区保持可见。
