# 项目概览甘特图选择交互设计

## 页面层级

项目概览从上到下排列：项目摘要、统计卡、状态/进度图表、排期区域、项目基本信息。排期区域内部上下排列主计划甘特图和子计划详情卡，避免同时铺开全部层级导致信息过载。

## 交互

- 主计划甘特图的条形支持点击，点击后记录 `selectedMasterPlanId`。
- 当前选中条提高边框和阴影，并在子计划卡片标题显示主计划名称。
- 子计划区域没有选中主计划时显示“请选择主计划”；选中主计划但没有有效日期子计划时显示空状态。
- 子计划甘特图数据由选中的主计划派生，主计划行置于其子计划行之前。

## 复用和边界

沿用现有 ECharts custom series、计划类型、状态颜色、图表局部滚动和语义主题变量。不新增接口或业务状态；选中状态只存在于项目详情页面生命周期内，刷新后回到未选择状态。
