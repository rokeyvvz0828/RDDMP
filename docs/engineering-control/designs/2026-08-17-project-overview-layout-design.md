# 项目概览信息与排期布局设计

## 决策

项目概览采用单列阅读顺序：项目与整体计划信息块、主/子计划排期、计划状态与执行进度图表。项目说明继续作为信息块中的补充区域，避免与整体计划进度分散在不同卡片。

## 交互与状态

- 主计划甘特图仍按月份展示，点击计划条后更新下方子计划甘特图。
- 子计划甘特图仍按周展示；未选择主计划和选中主计划无有效子计划时保持明确空状态。
- 图表容器维持自身横向滚动，页面主体不增加横向滚动。

## 非目标

不修改 API、数据模型、权限、计划进度计算、甘特图选择事件或主题 token。

## 复用说明

复用 ProjectView 已有项目概览卡片、统计卡片、ECharts 甘特图和语义主题变量；交付示范中心的项目详情/图表结构作为页面层级参考，无需新增公共组件。
