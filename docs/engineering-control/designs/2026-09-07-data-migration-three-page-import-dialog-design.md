## 目标与成功信号

将“迁移参数”“目标表结构”“中间表结构”三个页面统一为同一操作层级和批量导入流程：页面头部右侧依次展示次要操作“批量导入”和主操作“新增”，模板下载、Excel 选择、确认导入与结果反馈全部位于当前页面对话框内。

成功信号：

1. 三个页面均使用 `UiPageHeader`，批量导入在左，页面对应的新增主按钮在右。
2. 列表工具栏不再承载模板下载、文件选择或导入提交。
3. 用户不离开当前路由即可完成模板下载、选取文件、确认导入、查看结果和失败重试。
4. 三个页面复用 `dm-upload-dropzone` 与一致的文件、结果和移动端布局。
5. 既有 API、权限、项目范围、表结构分类、后端和数据库契约不变。

## 使用者与场景

- 有相应新增权限的数据迁移人员可从页面头部批量导入或新增单条记录。
- 无新增权限的用户不显示“批量导入”和“新增”入口，读取、导出和其他已授权操作保持不变。
- 项目范围继续由顶部全局项目切换器提供；导入对话框不新增项目选择器。
- “目标表结构”和“中间表结构”共用 `TargetTablesPage.vue`，由路由元数据 `category=TARGET/INTERMEDIATE` 区分，页面标题、按钮文案和导入请求分类随当前路由变化。

## 必须需求与验收条件

### R1 页面头部双操作

“迁移参数”页头部依次展示“批量导入”和主按钮“新增迁移参数”；表结构通用页根据当前分类依次展示“批量导入”和主按钮“新增目标表结构”或“新增中间表结构”。入口沿用各页既有新增权限、项目就绪、加载和错误状态约束。

验收：三个路由均有正确标题和按钮文案；批量导入始终位于新增按钮左侧且不是主按钮；无新增权限或项目未就绪时入口不可见。

反例：操作仍留在筛选工具栏；批量导入成为主按钮；目标表与中间表显示错误的新增文案或权限。

### R2 当前页面导入对话框

点击“批量导入”只打开当前页对话框。对话框包含导入说明、下载模板、Excel 拖拽或选择、已选文件、结果反馈、取消和确认导入，不新增路由或独立页面。

验收：打开和关闭对话框不改变当前路由、筛选或分页；工具栏不再出现模板或导入步骤；关闭后重新打开为干净初始状态。

反例：跳转独立导入页；模板下载仍在工具栏；关闭后遗留上次文件、错误或结果。

### R3 完整导入状态

对话框覆盖初始、已选文件、提交中、全部成功、部分失败、请求失败和关闭重置状态。未选择文件、项目不可用或提交中时确认按钮禁用；提交中禁止关闭和重复提交；成功或部分成功后刷新列表并保持对话框打开；请求失败保留文件供重试。

迁移参数结果展示总行数、成功数和失败数；表结构接口没有总行数字段，仅展示成功数和失败数。两类结果均最多展示 20 条错误及剩余数量。

验收：重新选择文件清理旧结果和请求错误；关闭、切换项目或切换表结构分类时清理导入状态；提交中遮罩、Esc、关闭图标和取消按钮均不能丢弃状态。

反例：成功后自动关闭；请求失败清空文件；部分失败只显示 toast；错误列表无界增长；提交中可关闭或重复提交。

### R4 工具栏职责

迁移参数工具栏只保留筛选、查询、重置、导出和批量删除。表结构通用页工具栏只保留筛选、刷新、查询、重置和导出；其既有表格底部批量删除保持原位。

验收：模板下载、批量导入和新增全部移至页面头部或导入对话框；既有筛选、分页、导出、选择和删除能力不回归。

反例：导入步骤仍散落在工具栏；移动操作时误删刷新、导出或批量删除。

### R5 上传样式与响应式

三个页面的导入对话框复用 `dm-upload-dropzone`、`dm-attachment-*` 和语义主题变量。对话框不使用已知会在移动端造成纵向拉伸的 `align-center`；正文设置最大高度和纵向滚动边界，底部操作保持可达。

验收：`1280x800`、`375x812`、`390x844`、`430x932` 下页面、对话框和正文无横向溢出；长文件名和长错误文本不撑破容器；长结果正文可滚动且 footer 可见；深浅主题内容可辨识。

反例：页面复制私有上传配色；手机端弹框被拉伸到近整屏或宽于视口；错误列表使底部操作不可达。

### R6 现有契约保持不变

迁移参数继续调用 `downloadParameterTemplate()` 和 `importParameters({ projectId }, file)`；表结构继续调用 `downloadTargetTableTemplate()` 和 `importTargetTables(category, projectId, file)`。`projectId` 继续来自 `useProjectScope()`，表结构 `category` 继续来自当前路由。Excel 字段、模板内容、权限、API、后端和数据库不变。

验收：不修改 `web/src/api/data-migration.ts`、路由、公共 UI、共享 CSS、后端或数据库；模板下载文件名与当前页面对象匹配；对话框不新增项目或业务字段。

反例：新增预校验 API；允许对话框覆盖项目或分类；修改模板列或服务端解析；抽取公共组件并扩大影响面。

### R7 共用表结构页的分类隔离

`TargetTablesPage.vue` 必须在项目变化或 `TARGET/INTERMEDIATE` 分类变化时关闭并重置导入对话框，随后按新项目和新分类加载列表。当前分类决定页面标题、新增文案、导入标题、模板下载文件名和导入请求参数。

验收：在目标表结构和中间表结构路由间切换，不会复用上一分类的文件、结果或文案，也不会把文件提交到错误分类。

反例：路由切换后仍显示上一分类结果；中间表导入请求携带 `TARGET`；模板文件名始终写成目标表结构。

## 不变量与约束

- 产品代码只修改 `ParametersPage.vue` 和共用的 `TargetTablesPage.vue`。
- 保留两个文件当前已有的未提交治理 diff，不覆盖其他人员修改。
- 复用 `UiPageHeader`、`UiToolbar`、Element Plus `el-dialog`/`el-upload` 和数据迁移共享上传样式。
- 权限继续由 `hasCreate`/`canCreate` 控制，前端不替代服务端 RBAC。
- 不修改 API、路由、共享 CSS、公共组件、后端、数据库、审计或迁移脚本。
- 仅写入 REQ-031 `writable_paths`；范围外 `REQ-061` 不处理。

## 非目标

- 不抽取新的跨页面或公共导入组件。
- 不新增独立批量导入页面或路由。
- 不增加导入预览、预校验、字段映射或导入历史。
- 不统一与本次三个页面无关的其他数据迁移页面。
- 不修改 Excel 模板内容或导入响应结构。

## 方案比较与选择

选择方案 A：在两个现有页面文件内复用迁移检核规则的已验证模式。该方案直接覆盖三个页面，保持各自 API 和结果结构，写入范围最小，也不会使已收敛的迁移检核规则页面重新进入变更范围。

未选择方案 B：抽取共享导入组件。它能减少部分模板重复，但需要同时修改已验收页面或公共组件，并为不同结果结构设计额外抽象，当前收益不足以抵消回归面。

未选择方案 C：只移动头部按钮，保留现有导入状态。它改动更少，但迁移参数仍会把结果放在正文，表结构仍会成功后自动关闭，无法满足“相同方式处理”。

## 架构边界与组件职责

- `ParametersPage.vue`：维护迁移参数列表、页面头部和参数导入状态；显示带总行数的参数导入结果。
- `TargetTablesPage.vue`：维护目标表/中间表共用列表、动态页面头部和分类隔离的表结构导入状态；显示成功/失败汇总。
- `UiPageHeader`：承载页面级批量导入和新增操作。
- `UiToolbar`：仅承载列表筛选与列表操作。
- Element Plus `el-dialog`：承载当前页面内的完整导入流程。
- Element Plus `el-upload`：单文件、禁止自动上传，实际提交由“确认导入”触发。
- `dm-upload-dropzone` 与 `dm-attachment-*`：提供三个页面一致的上传区和已选文件视觉。

## 接口、数据和状态流

迁移参数：

1. 下载模板调用 `downloadParameterTemplate()`，浏览器保存为“迁移参数导入模板.xlsx”。
2. 选取 `.xlsx` 或 `.xls` 后保存单个 `File`，清理旧结果和请求错误。
3. 确认时调用 `importParameters({ projectId }, file)`。
4. 成功响应保存 `rows/accepted/failed/errors`，刷新列表并保持弹框。

目标表/中间表：

1. 下载模板继续调用共用 `downloadTargetTableTemplate()`，浏览器按当前页面保存为“目标表结构模板.xlsx”或“中间表结构模板.xlsx”。
2. 选取文件后保存单个 `File`，清理旧结果和请求错误。
3. 确认时调用 `importTargetTables(resolvedCategory, projectId, file)`。
4. 成功响应保存 `accepted/failed/errors`，刷新当前分类列表并保持弹框。

## 错误、降级与恢复

- 项目未就绪：页面状态组件接管，头部入口不可用。
- 未选文件：确认按钮禁用，不发送请求。
- 请求失败：对话框显示可读错误，保留文件并允许重试。
- 部分失败：显示 warning 汇总和最多 20 条行级错误，刷新已成功写入的数据。
- 项目或分类切换：关闭对话框并清理文件、结果和错误，避免跨上下文提交。
- 对话框关闭：只清理导入状态，不清理列表筛选、分页或选择。
- 模板下载失败：保留对话框和文件状态，仅反馈下载错误。

## 安全、性能、兼容性与运维

- 安全：保持既有前端权限显示和服务端权限校验，不新增敏感数据或外部访问。
- 性能：错误列表最多渲染 20 条；上传仍为单文件，不增加并发或预读解析。
- 兼容性：API 参数、响应、Excel 内容和路由保持不变；Element Plus 交互沿用已验证实现。
- 运维：无数据库迁移、配置或发布流程变化；全仓治理若仍被 REQ-061 阻断，必须单独归因为范围外扰动。

## 验证策略

1. 静态契约：检查三个路由的动态标题、头部按钮顺序、工具栏职责、API 调用与重置逻辑。
2. 类型和构建：执行 `npm --prefix web run build`。
3. 差异与范围：执行 `git diff --check` 和 REQ-031 定向范围检查。
4. 浏览器：分别访问迁移参数、目标表结构和中间表结构，在 `1280x800`、`375x812`、`390x844`、`430x932` 验收初始、选文件、提交中、部分失败、请求失败和关闭重置。
5. 分类隔离：在目标表结构与中间表结构间切换，核对标题、模板文件名、结果重置和请求 `category`。
6. 视觉：检查页面、对话框、正文横向溢出、长文件名、长错误列表、footer 可达性和深浅主题。

## 假设、未知项与决策记录

- 假设：迁移参数 `hasCreate` 与表结构 `canCreate` 合法控制单条新增和批量导入，依据为现有页面权限实现。
- 假设：共用表结构模板内容同时适用于 `TARGET` 和 `INTERMEDIATE`，依据为现有单一模板 API。
- 未知项：无阻塞未知项；若浏览器验证发现共用模板只支持一种分类，应停止实施并回到设计，而不是修改 API。
- D1：采用两个文件覆盖三个页面的局部复用方案，不抽取公共组件。
- D2：成功或部分成功后刷新列表并保持对话框打开。
- D3：请求失败保留文件；关闭、项目切换和分类切换重置。
- D4：三个页面统一使用“批量导入”和“确认导入”术语。

## 风险与回退原则

- 风险：`TargetTablesPage.vue` 同时服务两个路由，若只监听项目不监听分类，可能泄漏上一页面状态。通过分类切换复验控制。
- 风险：原表结构弹框使用 `align-center`，与全局移动端样式组合可能再次产生纵向拉伸。新导入弹框不使用该属性，并复验三个手机视口。
- 风险：两个页面文件已有未提交治理改动。实施只追加本主题变化，最终按文件审查实际 diff。
- 回退：只逆向恢复两个页面中本主题加入的头部、导入状态、对话框和局部样式，保留此前治理 diff 和控制证据；无数据或迁移回退。
