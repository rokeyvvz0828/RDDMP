# 主题模式扇形切换设计

状态：已获用户确认

## 目标

把浅色、深色和跟随系统从“主题与布局”抽屉中独立出来，提供一个可在工作页面随时使用的模式切换控件，并让主题变化具有从触发点扩散到整页的视觉反馈。

## 交互设计

`ThemeModeFan` 是 `web/src/components/ui` 下的公共组件。中心按钮展示当前模式图标：太阳表示浅色，月亮表示深色，显示器表示跟随系统。点击中心按钮后，三个模式选项以固定半径和角度从按钮周围展开。选项采用图标加中文 tooltip，不使用重复的大文本按钮。

选择模式时组件记录中心按钮的视口中心，优先使用浏览器 View Transitions API 将新主题快照以 `clip-path: circle()` 从触发点扩展到覆盖视口，保证主题切换和扩散在同一个视觉层中发生。浏览器不支持该 API 时，使用固定定位的语义背景层执行同样的 `clip-path` 扩散。动画结束后清理临时状态。点击外部或按 `Escape` 只关闭扇形菜单。系统无障碍减少动画设置时直接切换并跳过扩散层。

`AppLayout` 在顶部导航和内容头部的 `header-actions` 中接入同一个公共组件；`ThemeSettingsDrawer` 删除“显示模式”区域，避免两个入口产生状态冲突。主题仓库和持久化结构保持不变。

## 组件边界

- 消费者：`AppLayout`。
- 状态 Owner：现有 `useThemeStore`，组件不复制主题状态。
- 视觉契约：使用 `--page-bg`、`--panel-bg`、`--line`、`--text`、`--brand` 等语义变量。
- 不引入新依赖，不改变 API、数据库或权限。

## 验收和风险

验收覆盖三种模式、两个桌面布局、移动视口、点击外部、`Escape`、刷新持久化、扩散圆心和减少动态效果。主要风险是头部空间不足和动画层遮挡，分别通过紧凑按钮尺寸、视口边界计算和动画结束清理处理。
