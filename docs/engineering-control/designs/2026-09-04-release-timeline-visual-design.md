# 投产方案时序图视觉设计

## 目标

在现有投产方案时序抽屉中，将指令列表表达为类似参考图的阶段列时序图。现有 `ReleasePlanItemDto` 没有独立阶段字段，因此以 `seqNo` 作为兼容的阶段编号，同一编号归并为一列，阶段标题由该列首条指令名称推导。

## 展示结构

- 抽屉保留时序名称编辑、指令统计和新增指令操作。
- 图形主体包含阶段列区、阶段列内的指令卡和底部横向时间轴。
- 阶段列头展示 `P${seqNo}`、兼容阶段标题、指令数和该列最早/最晚时间。
- 指令卡展示名称、时间范围、负责人、状态、说明和原有维护按钮。
- 时间轴节点与阶段列一一对应，标签使用阶段最早开始时间；轴线末端使用箭头表达方向。

## 响应式和状态

- 桌面端按内容宽度完整呈现所有阶段列。
- 移动端图形容器自身横向滚动，抽屉和页面外层不扩宽。
- 空数据、加载、失败、无权限逻辑继续复用当前组件状态。
- 长文本采用换行而非撑宽阶段列，操作按钮保持可达。

## 复用与边界

复用 `UiEmptyState`、Element Plus 抽屉/按钮/标签、现有语义主题变量和 release 模块样式。交付示范中心没有“投产阶段列 + 指令时序轴”这一业务形态，故仅新增该局部图形样式，不建立新的公共组件。无数据库、API、权限、审计或外部访问影响。
