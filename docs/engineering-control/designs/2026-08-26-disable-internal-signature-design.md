# 暂停内部电子签名设计

## 决策

采用兼容性停用：移除流程节点配置入口，并在工作流签名服务中统一关闭运行时签名要求。公开 DTO、请求字段、数据库结构和历史查询保持不变。

## 行为

- 管理员不能再为审批节点配置电子签名。
- 所有任务上下文均报告 `signature_required=false`。
- 审批决定继续执行原有授权、状态与动作校验，但不校验签名确认、不写入新签名记录。
- 历史 `wf_signature` 记录继续通过监控与详情接口返回。

## 风险控制

- 运行时开关集中在 `WorkflowSignatureService`，回退面清晰。
- 不删除 `signatureRequired` 模型字段，避免破坏旧流程 JSON。
- 不删除签名 API 字段，避免前后端版本错配。
- 不修改数据库，避免不可逆数据损失。

## 用户确认

用户于 2026-08-26 明确要求现阶段先去掉内部电子签名；此前已确认采用保留历史数据和兼容字段的方案。
