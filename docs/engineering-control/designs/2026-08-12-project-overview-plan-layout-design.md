# 项目概览与计划布局设计

## 目标

收敛项目工作台的信息层级，补齐主计划与子计划编号的可解释规则，并修复计划表固定列滚动遮挡。

## 方案

- 概览只渲染项目说明和由计划日期派生的项目日历，桌面端使用两列布局，窄屏自动纵向排列。
- 主计划使用项目级主规则和项目序号；子计划使用项目级子规则，默认 `{PARENT_CODE}-S{SEQ:3}`，序号保存在父计划上并独立递增。
- 服务端在事务内锁定项目行和父计划行，忽略客户端传入的 `plan_code`，同时保留租户、权限和层级校验。
- Element Plus 表格固定列使用主题面板背景、层级和阴影，滚动区仅在表格容器内滚动。

## 验收

后端覆盖主计划、子计划序列和不同父计划隔离；前端构建通过，并在项目详情和计划表横向滚动场景检查 DOM 布局。
