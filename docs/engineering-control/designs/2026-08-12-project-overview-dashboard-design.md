# 项目概览计划看板设计

## 目标

将项目概览从“基础信息 + 日历”提升为可扫描的项目执行看板，帮助项目负责人快速判断计划数量、状态、进度和排期。

## 方案

- 顶部使用三段式项目摘要：项目身份、整体进度、项目基本事实。
- 第二行使用六个轻量 KPI，状态使用现有语义颜色变量区分。
- 第三行使用 ECharts：环形图展示状态分布，横向条形图展示计划进度排行，堆叠横向条形图展示计划排期。
- 底部保留项目说明和 Element Plus 月历；月历仍由 `plans` 的日期字段派生。
- ECharts 实例由页面维护，监听项目/计划/页签变化更新，监听窗口变化 resize，卸载时 dispose。

## 边界

本轮只修改 `ProjectView.vue` 和 `styles.css`，不修改后端接口、数据库和现有项目权限逻辑。图表只消费已有详情响应，计划统计为空时使用空状态。

## 验收

- `vue-tsc` 通过。
- Vite 生产构建通过；如环境禁止 esbuild 子进程，记录为环境阻断。
- `git diff --check` 通过。
