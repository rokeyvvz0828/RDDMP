# 投产方案页面工程设计

## 文档状态

修订 1。设计已确认：用户对左右分区及抽屉方案回复“确认”，随后确认了落盘实施计划。本文记录该方案，不引入新的业务能力。

## 目标与使用场景

项目成员浏览方案并进入时序维护，管理员继续维护方案、时序及指令。目标是修正现有列表占主要宽度、详情被压缩和抽屉操作层级不清的问题。需求映射见 REQ-20260907-065 的 R1-R5。

## 方案选择

选择紧凑左目录、完整右详情，支持同屏切换和核对上下文。备选为整页列表后跳转详情，其浏览方案更适合批量比较，但增加往返步骤；本次不采用。

## 页面结构

- 页面顶栏：共享 UiPageHeader，标题“投产方案”，刷新图标和新增方案主操作，不显示英文眉题或介绍文案。
- 桌面主体：`minmax(240px, 300px) minmax(0, 1fr)` 两列。目录展示名称、编码、版本、状态和指令数，选中态同时使用边界和背景，不依赖颜色作为唯一反馈。
- 详情：方案名称、状态、编码和版本集中呈现，编辑与删除为次级图标操作；说明自然换行。下方两条横向入口区分正向和回退，保留名称、时序数、指令数与查看按钮，不使用嵌套卡片。
- 小屏：900px 以下上下排列；目录有限高并局部纵向滚动，详情内容自然展开；不新增整个页面的最小宽度或横向滚动。

## 抽屉与表单

时序抽屉保留现有最大 980px，手机宽度不超过视口。标题只出现一次，显示所属方案和时序类别，名称维护与新增时序形成明确的操作区。P1/P2 横向排列，每列宽度稳定，横向滚动限定在时序容器；指令按现有顺序显示。时序、指令工具按钮置于正常文档流，提供 tooltip 和 aria-label，不覆盖标题。

方案和时序编辑继续使用现有 dialog，指令继续使用 drawer；字段、时间范围选择、必填规则、保存和取消语义不变。弹层不超过视口高度，正文滚动，头部和底部操作可达。只读用户仍可查看，不显示写按钮。

## 组件、接口与状态

仅修改 `ReleaseDrillPlanView.vue` 模板、只读展示派生值和 scoped 样式。复用 UiPageHeader、UiStatusTag、UiEmptyState、Element Plus 图标、表单、dialog、drawer 和语义主题变量。保留 API 导入、请求函数、rowVersion、projectId、selectedId 及父组件的项目 key，不改变状态流或后端数据。

加载保留遮罩；空数据使用 UiEmptyState；请求失败保留错误与重新加载；403 保留无权限结果；保存保留 loading 与重复点击保护；删除确认保留对象与后果，取消/关闭不报错。

## 交付示范中心复用与例外

参考 DeliveryProjectList 的主次操作、状态标签、空/失败/无权限结构和移动端重排。其完整表格不是本页的目录与详情交互形态，因此不套用 UiDataTable；新增布局只在本组件内生效。继续复用共享 UI 和主题，不改公共组件或 release-operations.css，避免影响其他投产页面。

## 不变量与非目标

不更改业务字段、权限、API、数据、菜单或其他页面；不重新引入投产管理大标题、项目标识、统计块或日期时间线；不增加筛选、分页、排序等新业务能力。保留已有菜单改名的工作区变更。

## 验证与风险

检查构建、作用域、项目切换、方案切换、两个时序入口、三级 CRUD 入口与删除取消。桌面至少 1280px；手机 375x812、390x844、430x932，检查滚动宽度、长文本、弹层高度与浅/深主题。

主要风险是共享旧样式影响新布局、teleport 抽屉样式失效和移动端工具按钮溢出；使用独立类名与 scoped 样式，并逐视口实测。测试账号或浏览器限制导致未验证的场景必须单列，不视为验收通过。回退只撤销本次组件改动，数据无需补偿。无待决定的产品范围问题。
