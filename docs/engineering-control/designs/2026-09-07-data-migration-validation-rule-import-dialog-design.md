# 数据迁移“迁移检核规则”批量导入交互设计

## 目标

重组“数迁资产内容 / 迁移检核规则”页面的操作层级：将“批量导入”和“新增迁移检核规则”提升到页面头部右侧，并将模板下载、Excel 文件选择、确认导入与导入结果统一收敛到当前页面内的批量导入对话框。

成功信号：

1. 页面头部操作与“迁移方案”页保持同一结构和视觉层级。
2. 列表工具栏只承载筛选、查询、重置、导出和批量管理操作。
3. 用户无需跳转路由即可完成模板下载、选取 Excel、确认导入、查看结果和失败重试。
4. 桌面端和三个规定手机视口中，对话框内容无横向溢出，底部操作始终可达。

## 使用者与主流程

- 有新增权限的数据迁移人员：可在当前页面打开批量导入对话框，也可新增单条迁移检核规则。
- 无新增权限的用户：不展示“批量导入”和“新增迁移检核规则”入口，列表读取和既有授权操作不变。
- 项目范围继续由顶部全局项目切换器提供；本页面和对话框不新增项目选择器，也不展示动态项目名称。

主流程：

1. 用户在页面头部点击“批量导入”。
2. 对话框展示导入说明、“下载模板”按钮和共享全宽拖拽上传区。
3. 用户拖拽或选择一个 Excel 文件；页面展示已选文件名，可重新选择。
4. 用户点击“确认导入”，前端调用既有导入 API 并进入提交中状态。
5. 导入完成后，对话框内展示总行数、成功数、失败数和最多 20 条错误；成功或部分成功时刷新底层列表，但对话框保持打开。
6. 请求失败时保留所选文件与错误反馈，允许重试；关闭对话框时清理本次文件和结果。

## 必须需求与验收条件

### R1 页面头部操作层级

页面增加 `UiPageHeader`。标题使用“迁移检核规则”，说明延续当前项目范围语义。头部 `actions` 中按从左到右顺序展示次要按钮“批量导入”和主按钮“新增迁移检核规则”；新增按钮使用 `type="primary"`。两者的权限与项目可用性沿用当前页面既有判断。

验收：页面头部结构与 `PlansPage.vue` 的“新增迁移方案”位置一致；“批量导入”在新增按钮左侧且不是主按钮；加载或提交状态下不会重复触发操作。

反例：两个按钮仍留在筛选工具栏；“批量导入”被设为唯一主按钮；无新增权限时仍显示入口。

### R2 当前页面内的批量导入对话框

点击“批量导入”只在当前列表页打开对话框，不新增路由、不切换页面。模板下载、文件选择、确认导入和结果展示均位于该对话框内，不再散落于页面工具栏或列表正文。

验收：打开和关闭对话框不改变当前路由、筛选和分页；关闭后再次打开为干净初始状态；模板下载继续调用既有模板接口。

反例：点击后跳转独立批量导入页；页面工具栏仍保留“下载模板”“选择 Excel”或“提交导入”；关闭后遗留上次文件或结果。

### R3 导入状态与恢复行为

对话框覆盖以下状态：初始、已选文件、提交中、全部成功、部分失败、请求失败和关闭重置。未选择文件、当前项目不可用或正在提交时，“确认导入”不可用。提交中禁止关闭对话框和重复提交。全部成功或部分失败都刷新列表并保留结果供查看；请求失败保留文件供原地重试。

验收：每个状态都有可观察反馈；导入结果展示总行数、成功数、失败数，并最多展示 20 条后端返回错误；重新选文件时清空旧结果；关闭后清空 `pendingImportFile`、`importResult` 和文件输入值。

反例：未选文件仍可发起请求；提交中可重复点击或关闭；部分成功后结果立即消失；请求失败后强制重新选择文件。

### R4 列表工具栏职责

`UiToolbar` 只保留目标类型、规则大类、关联系统、规则关键字和内容关键字筛选，以及查询、重置、导出和批量删除操作。导入相关操作和结果均移出工具栏区域。

验收：工具栏不出现模板下载、文件输入、选择文件、提交导入或导入结果；现有筛选、导出、选择行和批量删除行为不回归。

反例：工具栏仍承担导入流程；调整头部按钮时误删导出或批量删除。

### R5 响应式布局与上传样式

对话框桌面宽度受控，移动端使用视口内可用宽度和可滚动内容区；底部操作固定在对话框操作层级内且可达。Excel 入口复用数据迁移模块的 `dm-upload-dropzone` 全宽拖拽样式，以及既有语义主题变量和文件名换行/截断规则。

验收：`1280x800`、`375x812`、`390x844`、`430x932` 视口无页面级和对话框级横向溢出；长文件名不撑破容器；内容较长时正文可滚动且底部“取消”“确认导入”可操作；深浅主题下边框、背景和文字可辨识。

反例：为本页面复制一套上传颜色或间距；手机端对话框超出视口；错误列表把底部按钮推到不可达区域。

### R6 契约与范围保持不变

继续使用 `downloadRuleTemplate()` 和 `importMigrationCheckRules({ projectId }, file)`，不修改导入字段、Excel 模板、权限、RBAC、项目范围、审计、后端或数据库。目标类型、规则大类、关联系统等行级字段仍由 Excel 内容解析，不在对话框重复要求用户选择。

验收：API 请求参数和响应类型不变；`projectId` 仍来自 `useProjectScope()`；不新增对话框业务字段；改动仅涉及 `ValidationRulesPage.vue`、对应设计/计划文档和当前 REQ-031 前缀账本。

反例：新增预校验接口或路由；允许用户在对话框覆盖项目；把 Excel 行级字段改为对话框级选择；修改公共 UI 组件或后端。

## 页面结构

桌面端：

1. `UiPageHeader`：左侧标题与说明，右侧依次为“批量导入”“新增迁移检核规则”。
2. `ProjectScopeState`：项目未就绪时维持现有状态页。
3. `UiToolbar`：筛选项和列表管理操作。
4. `UiDataTable`、空/失败/无权限状态和 `UiPagination`：维持现有列表行为。
5. 当前页对话框：说明与模板操作、拖拽上传、文件状态、导入结果、底部操作。

移动端：

- 页面头部操作按 `UiPageHeader` 既有响应式规则换行，不压缩按钮文字。
- 对话框宽度不超过视口可用宽度，正文设置明确的最大高度和纵向滚动边界。
- 拖拽区占满正文宽度，长文件名可换行或省略，错误信息允许断词。
- 底部操作保持“取消”在前、“确认导入”在后，确认按钮保持主操作样式。

## 对话框状态模型

| 状态 | 文件 | 结果 | 确认按钮 | 关闭 | 预期行为 |
|---|---|---|---|---|---|
| 初始 | 无 | 无 | 禁用 | 允许 | 可下载模板或选择文件 |
| 已选文件 | 有 | 无 | 启用 | 允许 | 可重新选择或确认导入 |
| 提交中 | 有 | 无 | 禁用并加载 | 禁止 | 防止重复提交和状态丢失 |
| 全部成功 | 有 | 成功统计 | 启用 | 允许 | 刷新列表，保留结果供查看 |
| 部分失败 | 有 | 成功/失败统计与错误 | 启用 | 允许 | 刷新成功行，允许调整文件后重试 |
| 请求失败 | 有 | 请求错误 | 启用 | 允许 | 保留文件，允许原地重试 |
| 关闭重置 | 清空 | 清空 | 禁用 | 已关闭 | 下次打开回到初始状态 |

## 组件与数据职责

- `UiPageHeader`：承载页面级“批量导入”和“新增迁移检核规则”。
- `UiToolbar`：仅承载列表筛选和批量管理。
- Element Plus `el-dialog`：承载导入流程；复用项目既有对话框和移动端样式约束。
- Element Plus `el-upload`：使用 `auto-upload="false"`、单文件选择和 `.xlsx,.xls` 接受类型；实际提交仍由“确认导入”触发。
- `pendingImportFile`：保存当前待提交文件。
- `importResult`：保存最近一次业务导入结果。
- 独立请求错误状态：展示网络或接口失败，同时不覆盖业务行级结果。
- `actionBusy`：沿用现有动作忙碌状态，阻止模板下载、导入提交或其他冲突动作重复触发。

## 错误、边界与恢复

- 项目不可用：页面由 `ProjectScopeState` 接管，导入入口不可操作；确认导入保持禁用。
- 文件缺失：确认按钮禁用，不发送请求。
- 文件格式：上传选择器限制 Excel 扩展名；后端仍是最终校验者，错误在对话框内展示。
- 部分失败：结果区显示汇总和最多 20 条错误，不把部分失败误报为全部成功。
- 请求失败：显示可读错误并保留文件；用户可直接再次确认。
- 项目切换：关闭导入对话框并清理文件、结果和错误，避免把旧项目文件提交到新项目。
- 对话框关闭：仅清理本次导入状态，不重置列表筛选、分页或选中行。

## 验证策略

- 静态检查：确认 `UiPageHeader` 操作顺序、`UiToolbar` 职责和导入状态清理逻辑。
- 类型与构建：执行 `npm --prefix web run build`。
- 差异检查：执行 `git diff --check`。
- 范围检查：执行 REQ-031 定向 `check-codex-scope`；全仓治理中的 `REQ-061` 失败仅记录为范围外扰动。
- 浏览器验收：在 `1280x800`、`375x812`、`390x844`、`430x932` 下验证打开、选文件、关闭重置、按钮禁用、长文件名、长错误列表和横向溢出；后端可用时补验全部成功、部分失败和请求失败重试。

## 风险与回退

- 风险：`actionBusy` 同时用于导出、模板下载和导入，若状态复用不当可能导致按钮互相锁定。实施时需明确每个入口的禁用条件并验证 finally 恢复。
- 风险：项目切换或对话框关闭时若未清理原生文件输入，重复选择同名文件可能不触发 change。关闭与选择后都需重置 input 值。
- 回退：该改动不涉及数据或 API，可回退 `ValidationRulesPage.vue` 的页面结构与状态变更；设计和控制记录保留为审计证据。
