# 工作流设计器企业级交互设计

## 文档状态

- 修订：1
- 状态：已确认设计
- 用户确认依据：用户确认按方案 A 改造工作流设计器，并要求解决流程删除、BPMN 节点区分、右键菜单、连线方向/条件、已发布流程查看和合理自动布局。

## 目标

将现有 Vue Flow 流程编辑器升级为可维护、可审阅、可发布的企业级流程设计器。草稿流程支持删除，已发布流程支持只读查看；节点使用 BPMN 语义外观，连线表达方向和分支条件，设计器提供节点/连线上下文操作以及分层自动布局。

## 必须需求与验收条件

### R1 流程定义生命周期

- 流程定义列表增加流程图查看入口。
- 只有草稿流程可以删除，删除必须带当前租户条件并采用软删除。
- 已发布流程不能删除、不能原地修改，但可以只读查看其发布版本流程图。

验收：草稿删除后不再出现在列表；已发布流程删除按钮不可用；点击已发布流程查看能加载固定版本图形且画布不可编辑。

### R2 BPMN 语义节点

- 开始/结束节点使用圆形。
- 人工审批使用圆角用户任务样式。
- 条件网关和并行网关使用菱形，并显示网关语义。
- 抄送节点使用独立消息/抄送样式。
- 节点颜色、图标和中文标签在深浅主题下均可读。

验收：新建流程时不同节点具有可辨识的形状和图标；只读查看与编辑态外观一致；节点名称溢出不改变画布布局。

### R3 节点和连线操作

- 节点右键菜单提供编辑、复制、删除、从此处添加节点。
- 连线使用有方向箭头；选中连线后可编辑名称、条件表达式和默认分支标记。
- 条件网关至少需要一条条件分支和一条默认分支，保存/发布时给出中文校验错误。
- 连线的 `label`、`condition`、`default` 字段从前端到后端完整保持。

验收：右键菜单执行后画布和模型同步；保存刷新后条件和默认分支仍存在；条件网关缺少条件/默认分支不能发布。

### R4 自动布局

- “整理布局”使用 Dagre 分层布局，默认横向 `LR`，支持切换纵向 `TB`。
- 布局考虑网关分支、节点间距和边界，避免节点重叠；手工拖拽后位置可以继续保存。
- 已发布查看图默认执行一次布局，但不写回服务端。

验收：含多个分支的流程执行整理布局后无节点重叠，箭头和标签可辨；切换方向后层级顺序稳定；保存后手工位置不被刷新覆盖。

## 数据契约

流程边统一使用以下字段：

```json
{
  "id": "edge-1",
  "source": "gateway-1",
  "target": "approval-1",
  "label": "金额小于一万",
  "condition": "${amount < 10000}",
  "default": false
}
```

流程详情返回定义元数据和当前可查看版本的 `definitionJson`。详情和删除均按 `tenant_id`、`deleted = 0` 约束；删除仅允许 `DRAFT`。

## 组件职责

- `WorkflowView.vue`：列表生命周期操作、编辑/只读查看模式、刷新和中文错误提示。
- `WorkflowDesigner.vue`：Vue Flow 画布、节点/边转换、上下文菜单、布局和模型同步。
- `WorkflowNode.vue`：BPMN 语义节点外观、图标、句柄和只读状态。
- `WorkflowNodeInspector.vue`：节点配置和边条件检查器。
- `workflow.ts`：详情、删除、定义图模型及边字段类型。
- `WorkflowModelAdapter.java`：保留边的条件、标签和默认分支。
- `WorkflowController.java` / `WorkflowService.java`：详情、软删除和固定版本查询。

## 约束与非目标

- 保持单租户、Spring Boot 3、JDK 17、MySQL、Vue 3、TypeScript、Element Plus、Vue Flow。
- 使用已有 Flowable 运行引擎和定义模型，不直接操作 `ACT_*` 表。
- 不改变已发布版本的运行语义，不实现 BPMN 全量规范。
- 不新增服务任务或消息事件配置；当前设计只为后续扩展保留节点类型入口。
- 所有页面文案使用中文，接口时间保持 `yyyy-MM-dd HH:mm:ss`，页面日期显示 `yyyy-MM-dd`。

## 风险与回退

- Dagre 依赖安装或构建失败时，回退到现有顺序布局，保留节点和边数据契约。
- 详情/删除接口回归失败时，前端隐藏生命周期按钮，已存在的发布和运行接口不受影响。
- BPMN 节点样式出现主题可读性问题时，仅回退样式变量，不回退模型数据。
