# 架构管理前端模块规则

适用于 `web/src/modules/architecture`，并继承仓库根目录规则和 `design-h5.md`。

- 本目录只承载逻辑子系统、物理子系统、部署单元及初始化导入、具体环境、资源申请、网络专项工单、架构规范和架构决策的页面、类型、API、组件和局部样式。
- 页面使用固定强类型表单，不接入动态表单元数据。
- 必须复用 `web/src/components/ui`、语义主题变量和统一 HTTP 能力，不得复制公共组件。
- 权限显隐只能改善体验，不能替代后端认证、RBAC、租户隔离和实体授权；部署单元维护写操作与导入仅对技术架构师（`architecture:deployment-unit:manage`）展示，资源申请草稿编辑、提交和取消仍必须以服务端申请人校验为准。
- 桌面端与手机视口都必须覆盖加载、空、失败、无权限和提交中状态。
