# 前端产品设计与可用性

## 用户任务与信息架构

- 首屏支持高频工作，页面标题、对象、状态、负责人和关键时间可扫描。
- 一个页面只有一个明确主操作；配置、导入导出和历史作为次要操作。
- 避免列表、详情和表单之间重复抄写数据，保留来源筛选和返回上下文。

## 列表与筛选

- 默认列服务于比较和决策；大量数据采用服务端分页、筛选和排序。
- 有限条件使用选择器，筛选变化回到第一页，区分无数据与筛选无结果。
- 批量操作说明选择范围、数量、部分失败和重试方式。
- 移动端按优先级重排为可操作布局，不压缩桌面表格硬塞。

## 表单与状态

- 按用户决策顺序分组，必填、默认值、单位和校验在操作前可理解。
- 字段错误靠近字段；联动隐藏字段不提交过期值；历史值可反显。
- 保存期间 loading 并防重复，离开时保护未保存内容。
- 每个异步区域覆盖首次加载、局部刷新、空、失败、无权限、过期和部分成功。
- 关键结果持续可见，不只依赖短暂 toast。

## 权限与危险操作

- 前端权限只改善体验，后端再次校验。
- 删除、撤回、覆盖、重置和审批驳回说明对象及后果，不使用含糊的“确定”。
- 完成后更新页面状态并保留审计证据。

## 响应式与可访问性

- 检查桌面、平板和手机；长编号、标题、附件名和错误信息不撑破容器。
- 弹层正文可滚动且底部操作可达；明暗主题具有足够对比度。
- 图标按钮提供 Tooltip 和 `aria-label`，键盘可到达主要操作，颜色不是唯一状态表达。
- 防止请求乱序、无界并发和重复请求；慢操作提供即时反馈和阶段状态。
